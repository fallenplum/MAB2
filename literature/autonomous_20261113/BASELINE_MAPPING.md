# 最近邻核验后的公平基线映射

核验日期：2026-11-13。结论是**已足以选择与限定基线机制，但不足以宣称外部方法原版复现或总体新颖性通过**。E2与CATS的方法、实验、局限和相关技术附录文本已覆盖；案例原题不属于本轮阅读范围。SafeSieve公开主文和官方MMLU代码路径已核查，外部Supplementary Material未取得。

## 必须优先保留的机制对照

所有方法固定模型池、初始图、初始反馈、价值预测器结构和更新代码，使用同一服务顺序、可编辑边集合、计价规则与停止预算。每个方法只能使用自身合法购买的反馈。

| 对照 | 可见信息与动作 | 要排除的替代解释 |
|---|---|---|
| 沿用旧信用 | 仅初始化反馈；后续不买新标签 | 改善是否来自更新本身 |
| 随机复检 | 在合法候选中随机选择；相同成本上限 | 是否只因增加测量次数 |
| 周期复检 | 预定周期和顺序，不看当前真值 | 是否只因更新时机 |
| 最大不确定性 | 同一预测器给出的U排序 | 是否只有不确定性采样作用 |
| 图变化驱动 | 仅使用编辑轨迹及旧信息选择 | 是否确为图条件失效 |
| 完整方法 | 决策相关性与成本归一化 | 是否在同完整预算下改善后续服务 |

固定节点作为主机制实验，另设允许删除节点的独立系统实验。否则减少代理调用可能替代通信边维护成为收益来源。删除与恢复使用明确、对称的净价值符号定义；不得把上一问题的gold用于同一问题再次挑选答案。

## SafeSieve：历史成功共现基线

来源：[论文v3](https://arxiv.org/html/2508.11733v3)、[固定官方提交](https://github.com/csgen/SafeSieve/tree/0af1b31474ae0107a4f6876b3dd6beb5dda6a9ac)。

- 可映射部分：角色先验与“答对图中出现过的边”的累积频次混合，然后剪枝。它能检验条件反事实信用是否优于廉价成功共现信号。
- 反馈权限：只能在实际获得最终正确性反馈后更新；未购买标签的服务调用不得自动提供gold。角色专家打分、初始化服务和最终聚合也计成本。
- 关键差别：这是最终成功共现，不是单边删除差。论文Eq.(11)已提出图变化后的历史权重调整，不能把该概念称为本项目首创。
- **官方代码不可直接作为论文忠实基线**：零扩展算子有合成反例；主入口的loss没有优化步骤；论文Eq.(2)/(4)/(11)与代码有差异；模型计价和生成参数传递不匹配。详见`NEAREST_NEIGHBOR_REVIEW.json`及`SAFESIEVE_SYNTHETIC_AUDIT.json`。
- 可行交付：独立实现并明确标成`SafeSieve-inspired history`，注明移除了节点裁剪、统一后端及成本；若实现论文零扩展与范围校正，单列`paper-based`版本，不能把修复当作者原版。

## E2-Explainer：离线反事实蒸馏基线

来源：[论文v2](https://arxiv.org/html/2608.12921v2)、[PDF](https://arxiv.org/pdf/2608.12921v2)。

- 最接近的映射：用开发校准任务对当前图逐边干预，冻结学习后的图到子图映射，在未来任务仅预测。它直接对照“离线一次学习”与“图编辑后持续复检”。
- 作者协议是每条边分别重跑原图与删除图，各5次且随机种子不配对；边分数裁去负任务贡献，再加0.2权重的语义熵信号。校准任务40/数据集，见附录A、算法1。
- 若复用共享原图、已有单次G2标签、删掉语义熵或改用带符号分数，必须称`E2-inspired`或`task-only`，不能冒充原版。主文rho称保留率，附录Eq.(29)定义删除率；执行协议应显式选择附录约定并注明差异。
- 完整成本至少包含原图与删除图的所有推理、语义等价判定、训练与服务。原论文在线token排除这些离线开销，不能拿其部署节省直接证明总预算收益。
- 先以N0固定节点比较，再以N20作为独立扩展。PDF第13页Table7显示E75+N0只节省5.27%总在线token，E25+N20节省25.10%。这些是作者报告，未复现。
- 尚未核实官方代码；语义等价划分、embedding具体模型、预算选择集等细节不足。**足以编写明确的适配协议；不足以承诺精确复现原表。**

## CATS：归因指导搜索的次级外部对照

来源：[论文v1](https://arxiv.org/html/2610.29292v1)，重点§2、§6与附录A.3–A.5。

- 节点信用来自更大的LLM对多个已评分轨迹的比较，再均匀传播到入边；它不是受控单边反事实，也不是固定预测器的复检政策。
- 如果执行适配：固定模型池与角色，搜索调用、judge调用、评分和未来服务均计完整预算。不能以相同候选数量替代相同成本。其原始基线已经明确只匹配候选数量。
- 原文的score-only是启发式，明确缺少REINFORCE的Bernoulli score-function因子，且未独立调参。不得把它称为强策略梯度基线。
- 原始实验有共享文件环境，部分无直接通信边的团队仍通过文件交互；MAB2需先锁定侧信道，才能解释“边”的作用。
- 权重哈希/量化未暴露，官方代码也未核实；因此目前应作为次级`CATS-style`适配，不能代替六项机制对照。

## 新核近邻：主动选择图训练任务

来源：[Active Learning for Communication Structure Optimization, v1](https://arxiv.org/html/2605.05703v1)。root与本子任务独立核了§4.1–4.4、§5.1–5.2及Figure1/Table1的核心权限/成本主张；附录与代码未核。

它从答案已知的训练池选择任务，昂贵动作是MAS rollout；信息增益使用ensemble/EKI近似。Figure1已经按8倍总MAS推理token比较主动选择（1倍训练+7倍选择）与8倍随机训练，Table1分列Select/Train/Test。故“把采集与训练计入成本”不能作为独有新意。

本项目可保留的候选差别是图编辑后的边复检、未来服务流与删除边恢复。若只选择额外训练任务或提出一般信息收益/成本比，则与该文距离显著缩小。先完成其附录、停止预算、surrogate和代码审计，再决定是否需要同一可观测信息下的EKI或信息增益适配基线。

## 验收与风险

优势：基线能分别检验廉价历史信号、离线反事实学习、持续选择性复检，且无需添加复杂预测网络。

风险：固定节点时边删除节省可能有限；复检开销可能超过服务收益；稀疏信用可能让主动策略无法优于随机。若独立确认未支持这些收益，应降级主张并保留负结果。

当前置信度：代码路径及合成反例为高；论文到MAB2适配可行性为中（未执行）；总体新颖性仍为PROVISIONAL。后续必须通过算子合成检查、反馈访问检查、完整成本单元账本和独立第二读者审查，再冻结正式实验。
