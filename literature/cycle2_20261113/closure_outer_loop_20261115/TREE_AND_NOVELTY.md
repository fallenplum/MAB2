# 第四轮之后的文献与机制复盘

2026-11-15 使用实际 web search 与 primary 页面核对。以下是摘要、方法段落阅读，不冒充全代码复现。沿用此前 Literature Tree 和 Novelty Matrix；这里追加直接影响第五轮的问题。

| 分支 | 可核对原始来源 | 已覆盖的概念 | 本项目尚需证明的差别 |
|---|---|---|---|
| 信息瓶颈 | [Yu et al., 2607.16133v1](https://arxiv.org/html/2607.16133v1) | 有限中继的信息保留与压缩权衡；MAS 对 SAS 的优势有条件 | 不能把原始证据访问或信息丢失当新贡献；本轮把所有节点的原始证据权限匹配 |
| 共同信息下的决策边界 | [Ao et al., 2603.26993v1](https://arxiv.org/html/2603.26993v1) | 共同信号下的集中 Bayes 决策支配性，以及通信损失 | 结论针对理想 Bayes 决策者，不是证明有限小模型单体一定最优 |
| 联合节点/边剪枝 | [Li et al., AGP 2506.02951v1](https://arxiv.org/html/2506.02951v1) | 任务自适应节点数量、通信拓扑及训练图数据 | 不宣称首次省略节点；应计入训练图采集、初始化和复检成本 |
| 一次性稀疏化 | [AgentPrune ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/bbc461518c59a2a8d64e70e2c38c4a0e-Paper-Conference.pdf) | 空间/时间通信冗余与一次性剪枝 | 图编辑后维护已获得的条件信用不同于一次性剪枝，但差别本身不等于有效贡献 |
| 决策价值采集 | [DIVA 2610.32181v1](https://arxiv.org/html/2610.32181v1) | 决策收益、成本和停止 | 普通 VOI 与成本归一化都不是本项目的新发明；需要同预测器的强 VOI 对照 |

此前完整上下文聚合是对照，不是第四轮成功提名。新方向的优势是消除人为证据分片的限制，并显式估计图编辑会改变哪些模型调用。风险是：图信用信号可能消失；维护成本可能超过服务省下的计算；拓扑感知 VOI 可能不优于普通 VOI、免费保护或固定剪枝。新颖性评级低，直到证明图演化中的真实维护增益；不使用“首次”表述。

候选路线区分：R1 的旧赢家差距选边已失败；两个图变更先验削弱/混合的贝叶斯开发诊断也没有优势，不继续调它们的超参数。这里保留旧信用观测，不因图变更自动衰减；新增假设仅为真实调用闭包改变删留阈值、采集价格与停止时机。所有策略共享同一执行优化，执行优化本身不能算方法胜利。
