# Root verification and publication scope

This is a bounded literature/theory review, not an admitted empirical candidate.
The root independently opened the official UAI 2023 record and selected Section 2
of its paper and checked the weighted unknown-item term and known-contribution
subtraction. This is a direct prior for the proposed uniform-bank identity.
The arbitrary exact side-feedback extension is checked in the accompanying
mathematical note, not represented as a verbatim theorem from that paper.

The root also inspected the pinned aLTT LLM implementation's exploit and forward
paths. They use the global t-1 row; the per-arm row expression is commented out.
The selected software audit therefore does not support the alleged adaptive
cross-arm row-reuse defect. This is not a full replication or proof audit of aLTT.
Only software provenance hashes and this description are published; no third-party
source, credentials, benchmark rows, cached predictions or model assets are included.

Public primary sources: [UAI 2023](https://proceedings.mlr.press/v216/shekhar23a.html),
[aLTT ICML 2025](https://proceedings.mlr.press/v267/zecchin25a.html),
[pinned aLTT source](https://github.com/kclip/aLTT/blob/b071916f44cf1cea2892b0ecd51736598c5d446e/LLM/code/automatic_prompt_engineer/altogether_ape.py).

Decision: reject novelty of the generic finite-bank correction itself. A graph
execution/acquisition advantage remains unestablished and would need equal-cache,
equal-information, complete-cost baselines plus separate future-service evidence.
No formal round, model call, GPU reservation or project stop follows from this review.
