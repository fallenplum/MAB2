# 数学检查：固定银行、完整历史与精确侧反馈

以下是独立代数检查，不是新定理，也不是实验算法实现。

令有限银行 Y_1,…,Y_N 为固定实数，L ≤ Y_i ≤ U，目标 μ=Σ_iY_i/N。若银行最初随机生成，以下保证先条件于整个已固定银行。F 是抽样前完整历史，包括所有臂的反馈、缓存、部分线索和当前臂选择。K 是此时精确已知值的集合，k=|K|，S=Σ_{j∈K}Y_j；K 可以偏选、随机且一次增加多项。

当 k<N，必须在给定完整 F 后，重新均匀抽 I∈[N]∖K。令

    X = S/N + (N−k)Y_I/N.
    E[X | F] = S/N + Σ_{i∉K}Y_i/N = μ.

条件均值成立不要求 K 是均匀样本。边之间相关也不破坏这个逐步等式。关键是实际索引分布与完整历史一致；公开的预排索引流若因别臂反馈而被条件筛选，不能自动视为仍均匀。每项只进入已知和一次，近似标签不等于精确值。每次过程更新后才进入下一步历史；不能在看到当前新值后反选本次赌注。

可预测范围与不含概率的逻辑银行区间为

    a = [S+(N−k)L]/N,  b = [S+(N−k)U]/N,
    X∈[a,b], μ∈[a,b], w=b−a=(N−k)(U−L)/N.

当 k=N，μ=S/N 已知，不再抽样。逻辑区间与任何有效 CS 相交仍有效。侧反馈到达时可以更新逻辑区间；不能把无随机抽样保障的每个侧标签当成独立新下注样本。

对 H0:μ≤m，标准条件 Hoeffding 引理给出：若 λ_t≥0 是抽样前可预测值，

    M_t(m)=∏_{s≤t} exp{λ_s(X_s−m)−λ_s²w_s²/8}

是初值 1 的非负超鞅。未选该臂的全局步骤因子为 1。Ville 不等式给出任意停止的单个假设错误拒绝概率上限 α。这里概率针对银行上的抽样随机性。不同臂/时期仍须合法分配多重检验错误预算；“单条 anytime”不自动等于整个持续部署 FWER。图或效用定义改变就可能改变目标银行，不得直接沿用旧证书。

更一般地，给定完整 F 后用已知 q_i>0 抽未知项，则

    X = S/N + Y_I/(Nq_I)

同样条件无偏。若 f_i 是抽样前已知预测，则

    X = S/N + Σ_{i∉K}f_i/N + (Y_I−f_I)/(Nq_I)

也是条件无偏的差分/控制变量估计。非均匀抽样必须重算合法范围，不能沿用均匀情形的 w；零概率的未知项会破坏该推导。预测器是否有帮助属于方差与费用问题，不能从无偏性推出。

与先例的直接对应：UAI 2023 §2 的 Z=f(I)π(I)/q(I)，剩余目标 m−Σ已观测πf。取 π=1/N，令 Y 先仿射缩放到论文的 [0,1] 定义域，则 Z−剩余目标正是本检查的 X−m。原文写逐项已观测前缀；任意外部精确集合 K 的情形由上面的完整历史等式单独核验，不声称原文逐字覆盖批量侧揭示。[原文](https://proceedings.mlr.press/v216/shekhar23a/shekhar23a.pdf)

手工算例：Y=(−1,0,0,1)，偏选 K={第4项}，μ=0。未知集合均匀抽样时 X 的三个值为 (−1/2,1/4,1/4)，平均为 0；直接把剩余值均值当完整银行均值会得到 −1/3。该例只检查代数，不提供任何方法性能证据。

错误迁移的反例（不针对 aLTT）：两臂同一行结果满足 Y^A_i=Y^B_i=Z_i，Z_i 为等概率 ±1。先看 A_i，再仅在 A_i=+1 时把 B_i 当作“新的均值为 0 的独立样本”下注，其条件均值实际上为 +1。问题是被筛选的索引/错误历史，不是“所有跨臂相关都违法”。若 B_i 已被精确确定，应作为精确已知项利用，或按合法随机抽样/抽样概率修正。

边界：固定种子使银行中的单次生成结果固定，但不自动证明跨运行数值确定性；执行器必须有适用的身份与重放证据。基图共同、前缀共同、wire 相同等条件只有在确实决定目标 Y 时才产生精确侧反馈；否则只是可用于排序/控制变量的线索。成本归一化也必须先固定目标及其界，不能把随机 token 比率默认为上述加性均值。认证银行平均正净收益既不意味着每题无害，也不意味着未来服务平均获益。
