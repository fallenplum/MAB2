# 风险受限图编辑：文献核查与可证伪设计

日期：2026-11-13。状态：只读外循环审查完成；没有新实验结果、方法有效性结论或 GPU 启动授权。

**结论：将“旧信用只用于排序 → 新鲜配对反事实 → anytime 检验正收益 → 才编辑”作为独立算法创新，现有证据不支持，置信度高。** aLTT、MOPE、传统 simulation comparison-with-a-standard 已覆盖主要统计结构；共享计算费用也有 NeurIPS 2020 的直接先例。至多保留两个明确可失败的问题：旧信用排序是否减少认证费用，以及图重算闭包调度能否超越通用可变成本分配。当前后者新颖性尚未建立，置信度低。

## 先固定研究对象，才谈“风险受限”

以下是对拟议实验的条件分析，不是新定理。

在冻结的 epoch 中，固定基图 G、候选边集合、模型/模板/解析器、任务分布 P 和独立新任务抽样规则。定义同任务合法配对：

Y_e(q,z) = Q(q,G⊕e,z) − Q(q,G,z)，Q∈[0,1]，所以 Y_e∈[−1,1]。

若 Q 为二元正确性，则 Y_e∈{−1,0,1}。设 r=P(Y_e≠0)、p=P(Y_e=1 | Y_e≠0)，有 E[Y_e]=r(2p−1)。这只是代数恒等式：大量平局不能通过只保留赢/输、忽略其发生频率而获得正的**绝对净收益**证据。零费用、零阈值的符号方向与带正费用/正收益门槛是不同命题。若 r=0，条件 p 不定义，而均值为零。

成本至少拆成三部分：

1. 已支付的基图服务成本：各方法共同享有，边际反事实费用中可不重复收取；完整系统总账仍保留。
2. 未来部署的服务成本差：ΔC_service,e；若 λ 为固定质量/成本换算率，认证目标可为 μ_e=E[Y_e−λΔC_service,e]。
3. 为取得认证而支付的反事实、评分、失败与调度成本 C_verify：独立记账。若声称系统净收益，须在预先固定未来服务跨度 H 下检查 H×μ_e−λC_verify，不能把“每次采集费用”偷偷当成“每次部署费用”。

若成本项无已知界，不能直接把净收益送入有界 CS；必须先固定合法范围或另选适用推断工具。没有真实质量标签时，基图输出不是质量反馈；人工、参考答案或 judge 的获得成本与测量误差均要申明。

**可保证的对象至多是固定目标分布上的期望改进。** 它不等于每道题不受损，也不等于当前分布会一直保持，更不等于累计服务收益约束。这一点与保守 bandit 的累计奖励约束相区别。

## 有效性与信息权限：九个必须关闭的漏洞

1. **选择题目造成偏差。** 先看到当前基图答错、长消息、receiver 变化再选择反事实，会改变该边被评估的任务分布。最小合法版是在观察当前样本输出前冻结待测边/批次；如允许基于当前输入或输出挑边，要重定义条件目标，或提供具有正采样概率的合法校正。任意停止有效不等于任意挑样本有效。
2. **不能把历史信用当新证据。** 可用于排序/可预测采样分配，不能未经可迁移性证明直接作为新图均值的伪观测。
3. **冻结 epoch。** 一次真实编辑后，其他边的目标可能变化；默认重置/重新认证。跨图复用证据需要额外假设与证明。
4. **控制全部编辑的错误预算。** 单边 δ 不等于多边、多 epoch 总体 δ。可用预先分配且总和受限的错误预算；相同 base 引起边间相关时，不能套需要独立性的合并规则。需要“任何错误编辑”控制时选 FWER，不能用 FDR 悄悄替代。
5. **题目是依赖簇。** 同题多个 seed 不能充当独立任务；共享 seed 的边间依赖需保留。CRN 可帮助也可能无益，效果必须实测，不能由“同数字 seed”推出降方差。
6. **缓存以完整请求身份为准。** 同模型、tokenizer、完整多父输入、生成参数、seed 与解析协议等均应匹配；不同图中同名 aggregate 节点未必同请求。按 DAG 节点 ID 的闭包并集不等于可重用计算并集。
7. **稀疏不会免费揭示。** 只有在合法完整输入/输出等价已证明时，才可省略下游；为了发现“无变化”已经执行的 receiver 不能回填为免费。所有方法使用同一精确缓存。
8. **有限银行与未来服务分开。** 随机无放回银行证书只针对该有限总体；不能直接宣称外推到新任务流。公开历史题上的探索不等于独立确认。
9. **预算耗尽应保留现图。** “未认证”不等于“负收益”。零效果附近可能需很长观察，明确硬预算与最小实质收益阈值；不为获得显著性不断延长。

## 最多两个可证伪设计

### 设计一：旧信用排序是否仍有决策信息（应用性贡献）

**假设 H1。** 在全新的冻结图环境与任务批次上，旧信用提供的预定排序能减少首次认证正净收益编辑所需的完整反馈费用。它只声称排序价值，不声称新 CS 或保证更低 MSE。

**最小比较。** 所有方法共用候选集合、fresh stream、有效认证器、FWER 总预算、精确缓存和硬成本上限；只改采集次序/分配。至少含旧信用固定排序、随机/均匀、按合法预估边际成本排序，以及任务适配的 GAI 或 aLTT 采集。单纯只比较随机与 LUCB 不足。根据当前未揭示样本输出改排序不属于此最小版。

**预先固定评价。** 在所有独立 epoch 上报告：预算内认证概率、认证费用的截断期望/完整分布、未认证支持数、错误认证检查以及固定 H 上含验证成本的服务效用。不能只在成功认证的 epoch 上比较平均费用。服务质量评分留到政策冻结后；最终封存测试只做一次确认，不能拿来改顺序、δ、H、λ 或预算。

**可证伪预测与停止。** 若旧排序相对均匀及成本排序没有预先规定的实质费用优势，或优势以更高误编辑/更低含成本服务效用换取，则放弃“信用迁移带来效率”主张。不能从未提名的排序策略里补选赢家。因任务全无正收益编辑而均未认证，应报告该环境无决策机会/证据不足，而不是推断所有信用维护无效。

**优势：** 与原研究问题一致，机制清楚，避免新增预测网络。  
**劣势与风险：** 即使有效也主要是应用性证据；既往负结果意味着有效排序仍未证明。效果置信度低，新颖性不足的判断置信度高。

### 设计二：闭包和缓存状态能否改善风险约束下的采集效率（尚未建立的方法候选）

**假设 H2。** 在同样有效认证器和完全相同精确缓存下，根据待计算请求的重叠与缓存状态安排反事实批次，可优于通用可变费用分配，并在固定未来跨度 H 内收回采集开销。

**必要区别。** 成本应写成 C(S,K)：候选集合 S、当前合法缓存 K 对应的完整请求指纹集合成本。它通常不是常数 c_e 的简单相加；但这并不自动给出次模性，也不自动意味着新颖。请求内容和长度未产生前，预估费用与实际费用分开记录；共享前缀不代表所有受影响 suffix 可合并。

**不可省略的强比较。** aLTT/GAI 的同认证器版本；Zheng 2020 风格的“预计界改进/实际可得边际费用”通用策略；固定独立费用策略；同缓存的均匀/成本贪心。CAET 等仅在明确观测假设和目标适配后纳入，适配版不能冒用原定理标签。所有方法可同等访问已支付 base、结构和缓存元数据；任何新增信号获得费用均计入。

**可证伪预测。** 除真实独立任务上的费用与固定 H 服务效用外，预先定义低/高闭包重叠条件。仅在有重叠时出现、且对通用可变成本策略仍存在的额外优势，才支持图结构专属机制。合成等价费用/无重叠条件只用于机制反例，不代替真实任务。若共享缓存公平化后优势消失，则归因为通用 memoization；若只赢固定成本弱对照、未赢通用状态成本策略，则不得声称图结构分配创新。

**优势：** 直接面对验证稀疏收益所需的实际费用，可能产生可重用的执行/统计系统贡献。  
**劣势与风险：** NeurIPS 2020 已覆盖可变共享计算费用，Shepherd 已覆盖后缀重放；新颖空间窄。调度若依赖当前样本输出，还可能制造选择偏差。没有新的结构性费用界、合法效率保证或稳定超强对照实证时，应降级为应用/工程贡献。当前可行性与新颖性置信度均低。

这两个设计是候选科学问题，不是冻结实验合同；本次没有指定新 GPU 预算、扣除正式候选轮次、运行 power simulation 或提名待测实现。任何后续执行仍需主任务在既有总预算内冻结数据、阈值、成本、对照、风险分配和停止规则。

模型路由、异构 tokenizer、确定性重放、费用闭合和 watchdog 资格验证属于 supportive engineering。它们能证明执行器具备可用条件；即使全部通过，也不提供新方法准入、有效性或科学新颖性的证据。

## 主张处置与审稿风险

| 拟议主张 | 本轮处置 |
|---|---|
| 首个用置信序列保护图编辑的通用方法 | 不支持；应用对象变化不足以覆盖 aLTT/MOPE/标准比较先例。 |
| 首个多智能体配对反事实顺序验证 | 放弃；EvoSteer 已直接重叠。 |
| 首个共享基图/局部重放以降低验证成本 | 放弃；Shepherd 与共享计算分配研究已存在。 |
| 旧信用能提高新环境认证效率 | 保留为 H1，尚无新证据。 |
| 图闭包状态分配优于通用变成本分配 | 保留为 H2，尚无新颖性或效果证据。 |
| 在任意漂移下保持未来服务安全 | 不支持；所核 CS 目标与这一主张不同。 |
| 稀疏信用使正净收益认证更便宜 | 不支持；非零事件稀少可能让绝对效应更小，且反馈仍需付费。 |

研究、统计和系统三个视角的共识是：先证明旧信息或闭包结构带来**超出通用有效检验与公平缓存的效率**，再谈方法贡献。若两项均失败，应保存一个清晰的应用性负结果：在指定环境、错误预算、未来跨度及完整成本下，认证/维护没有覆盖费用；不能把它扩大成图信用维护普遍不可行。

## 复核与局限

PAPERS.json 保留每篇身份、版本、URL、实际阅读深度和未核部分；SEARCH_LOG.json 保留实际检索与访问失败。委派代理独立读了传统仿真选择、LTT 和共享成本先例，关键重叠由本代理再次读原文交叉核对；没有把摘要阅读冒充全文审查，也未宣称完成所有定理证明验证。

按本次使用的 paper-lookup/literature-review 技能要求记录工具来源：[Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents，Kassis et al., 2026](https://arxiv.org/abs/2609.00065)。技能提供检索流程，不构成文献正确性或研究有效性的独立证据。

**交付边界：文献核查与两个设计问题已完成；新方法有效性、正式实验、独立测试与论文贡献均未在此获证。**
