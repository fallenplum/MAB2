# Cycle3 literature tree and claim boundaries

This is a mechanism map, not a claim of exhaustive retrieval. Preserve the historical30-paper inventory and subsequent Cycle2 addenda; read-depth and source metadata remain in their original records.

1. Graph construction and sparsification: G-Designer, GTD, AgentPrune. Existing task-conditioned topology and graph editing prevent a first-dynamic-graph claim. Historical primary-source pointers: ../cycle2_20261113/receiver_outer_loop_20261115/TREE_AND_NOVELTY.md.
2. Grounded communication and compression: MessageSieve, PACT, CompAct. Cycle3 primary records and PACT code audit distinguish message instance filtering, action/state/result communication and document compression. Their existence rules out novelty from short structured messages alone.
3. Exact executed attribution: The Trace Is the State and replay-noise work. Trace equality is a conditional execution fact, not a universal semantic guarantee. Same prefix, RNG, backend and evidence permissions matter.
4. Budgeted feedback and downstream decision value: filtered-feedback marginal policy gradients, DIVA, resource-limited best-arm work. Query allocation weighted by variance/cost is established. Full-budget graph utility remains an empirical question here.
5. Distribution shift and historical evidence transfer: adaptive temporal model selection, causal contextual-bandit transportability, clustered/nonstationary bandits. Their assumptions do not automatically hold for interventions on an agent communication graph.

Cycle3 D6 and D7 already reject simple input/prefix-feature transfer routes under their fixed exploratory gates. Formal6 tests a different evidence representation while preserving the project question. Its result is pending and cannot support a final policy, novelty or ACL-readiness claim.

The remaining candidate contribution, if supported, would be a decision-relevant maintenance rule that uses graph-induced evidence changes to spend scarce counterfactual feedback better than free structural rules and standard sampling, with shared execution optimizations and all costs charged. This statement is a falsifiable target, not a result.
