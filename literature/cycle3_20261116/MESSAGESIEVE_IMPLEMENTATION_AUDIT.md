# MessageSieve primary implementation audit

Paper: https://aclanthology.org/2026.emnlp-main.2179.pdf . Read methods3 and appendixA. The policy uses deterministic receiver-local message views and preserves the final judge inputs. Its task-specific parsing and view rules need explicit adaptation before applying to a document-ID protocol. The published comparison freezes structural baselines and separates evaluation tokens from adaptation. This does not establish full-cost online superiority over native updating SafeSieve. One main-table run is reported. These scope differences prevent transferring reported gains to MAB2.

Primary code: https://github.com/NianhaoYou/MessageSieve/tree/580728b9251467009c702ccbfc7c1f65f887b967 . MIT license. Only code/configuration sparse-checkout; benchmark files not opened. Reviewed CardBuilder, routing interface, QA relation keys and the judge pass-through. `configure(task_family="qa")` accepts an explicit QA adapter, while the convenience dataset mapping does not list HotpotQA/2Wiki. `_answer_key` has a multiple-choice letter rule; an open-answer adaptation must disclose any change rather than claim exact replication.

Artificial CPU interface check: structured answer/evidence messages retain two messages; two short document-ID arrays parse no answers, are marked low-content, and retain one. This establishes an interface mismatch, not task quality. Original inputs and dense judge messages are preserved; per-run card/history reset is verified. Ordinary package import failed on Windows because unrelated code judging imports Linux `resource`. A namespace-only loader executes unchanged routing modules without full runtime initialization. This is not a full reproduction.

A matched experiment must retain every baseline's legal information, final-judge behavior, actual prefix cost and stable ordering. Passing ID arrays directly through QA heuristics and reporting the resulting handicap as superiority would be invalid. Author performance has not been reproduced; no MAB2 labels or model calls were used by this audit.
