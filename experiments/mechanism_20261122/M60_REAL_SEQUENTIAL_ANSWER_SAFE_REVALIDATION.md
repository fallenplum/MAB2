# 顺序式条件复检与答案区域诊断

该候选在训练题中估计每个编辑行的最大 TV 漂移，在留出题上按 token 成本排序逐行复检。当图决策区间和当前最终答案区间都无法证书化时继续查询。

| 任务 | full mask 答案准确率 / token | 顺序式答案安全复检准确率 / token | max-uncertainty 答案准确率 / token |
| --- | ---: | ---: | ---: |
| QASC | 25.40% / 230.33 | 25.40% / 131.63 | 26.98% / 99.48 |
| SciQ | 52.17% / 206.99 | 52.17% / 114.01 | 62.32% / 89.48 |
| CommonsenseQA | 52.08% / 209.75 | 52.08% / 132.94 | 45.83% / 90.75 |

顺序式候选在三个任务上复现了 full mask 的答案准确率，同时减少约 36%–45% 的 full-mask token。它仍未超过最大不确定性策略的跨任务答案准确率，且经验 TV 半径无法保证独立留出题上的答案动作完全一致。因此该结果支持“安全重验证的成本压缩”机制，不足以支撑跨任务服务质量领先主张。
