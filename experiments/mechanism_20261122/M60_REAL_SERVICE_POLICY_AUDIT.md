# 真实标签服务质量策略审计

使用本地私有 M60 条件输出和真实封存答案标签，按任务留出训练复检策略。训练输入为旧/新 source 分布、旧 relay 分布、图变化掩码和 token 价格，评估为最终答案准确率与复检 token。

基于决策影响标签的策略在 CommonsenseQA 留出集 top-1 平均答案准确率为 0.5486，最大不确定性为 0.4583，平均 token 为 90.37 对 90.75。在 SciQ 上策略为 0.5556，对照为 0.6232。在 QASC 上两者均为 0.2698。答案对齐分类器和答案增益回归器均没有稳定超过最大不确定性。

结论是存在任务依赖的可学习信号，但没有形成跨任务稳定的服务质量优势。该结果保留为候选失败和机制诊断，不能作为 ACL Main 结果。
