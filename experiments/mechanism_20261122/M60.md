# M60 CTDR 图编辑证书传输候选

## 假设

在图编辑后，旧 transcript 能否继续支持 keep/remove 取决于阈值 margin 与 graph drift，而不是全局预测不确定性。使用 row-level TV transport bound 进行安全复用，并将 feedback 分配给 action-region crossing 最大且单位成本风险下降最大的查询，应在相同反馈预算下降低错误图编辑和逻辑 token。

## 方法

对每个边和可能答案维护旧图信用区间。图编辑后计算

\[
B_y=\sum_i |s'_i-s_i|+\sum_i s'_i\bigl(\operatorname{TV}(q_i^{1'},q_i^1)+\operatorname{TV}(q_i^{0'},q_i^0)\bigr).
\]

若区间加减 $B_y$ 仍在阈值同侧，直接复用旧证书。否则，对候选反馈 $t$ 计算逐标签区间收缩的上界，按
`sum_y unresolved_action_margin_reduction(t) / cost(t)` 选择下一项。查询结果更新区间，直到所有 service-action 或 all-label certificate 可判定。

## 对照

Stale reuse、full restart、random feedback、periodic feedback、maximum interval uncertainty、source-TV-only、oracle target-aware certificate。所有方法使用相同模型池、旧初始化、图编辑、反馈预算和 prompt。Oracle 只作下界，不作为可部署比较。

## 新独立实验

使用尚未进入 MAB2 研究工件的 QASC 或 ARC 题目，至少 192 题、三个模型 checkpoint、三种角色轮换。题目只按一次独立样本计数。图编辑为真实上游证据边删除或替换，源和终端结果由实际模型产生，answer key 只用于离线评分。

## 预注册主门

1. 每个任务至少两个模型团队的 action decision accuracy 高于 stale 和 maximum-uncertainty，且误删与误保均不增加。
2. 相同逻辑 token 预算下，CTDR 的最终 action regret 比最强非 oracle 对照至少低 10%。
3. 至少两个团队的反馈 token 比 full restart 少 20%，同时与 full restart 的完整 decision set 逐题一致。
4. 去掉 row-level TV 或 action-margin 任一组件后，主门至少有一个任务失败。

若第 1 或第 2 门失败，候选淘汰，不改写门槛。若算法只减少 token 但不改善图决策，降级为工程结果。
