# CTDR ACL-style manuscript

`main.tex` is the ACL-style source and `main.pdf` is the five-page compiled author-review draft. Recompile twice with `pdflatex -interaction=nonstopmode -halt-on-error main.tex` in a directory containing the included `acl.sty`.

The formal positive evidence is M60 CTDR on four disjoint input panels (QASC-A/B and SciQ-A/B), with 192 questions and three shared-question model teams per panel. Earlier M50/M54/M56/M59 results remain historical exploratory or negative evidence and are not merged into the M60 positive aggregate. The primary claims are restricted to the finite four-row interface, source-edge edit, fixed conditional relay channel, and declared incremental logical-token accounting. The fresh finite audit is a reference certificate set rather than a task-accuracy oracle.

Question-level arrays, answer keys, model weights, credentials, raw token traces, and server paths remain private. The public branch contains the contracts, sanitized receipts, worker and CTDR implementation, baselines, ablation, formal summary, audit report, peer-review check, and reproducibility notes.
