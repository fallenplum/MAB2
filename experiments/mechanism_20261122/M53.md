# M53 同一查询轨迹上延迟指定目标的实际费用

M51/M52 的事后最短证书不能等价为实际调度器能节约的 token。M53 固定由 M46 开发集选择的联合策略，同一条合法在线查询轨迹上，同时监视每个标签的证书。算法选下一个动作不使用黄金标签。当只需已知标签 y 时，首次证实其方向的时刻为 T_y；未知标签时需要 T_all=max_y T_y。原因是各标签证书随已知观测单调，一旦成立就永久成立，监视更多标签不会反过来改变本策略选取动作的顺序。这个恒等式不适用于会根据目标改变查询次序的策略。计算轨迹每次早停前真实已产生的输入及输出 token，含启动成本。M50 在同形批次实际执行无标签联合路径；与逐题逻辑账核对，不能将移除其中一些序列的 token 直接换算成 GPU 时间。

在 M45 的两个选择题数据、M49 的有来源材料三角色组合和 M46 的数值题开发数据上描述两者差异。在未揭示的 M50 上，三个模型×两个年级组均有 T_all/T_gold≥1.15 才支持延迟指定目标产生实质额外费用。本项只讨论合法答案，INVALID 的花费照计但不能作为数值真值；未来完全未见数值始终检验。报告真实标签最后一个才得到证书的比例、总成本比、每题额外 token 和实例数。任一任务下没有额外成本的题完整保留。
