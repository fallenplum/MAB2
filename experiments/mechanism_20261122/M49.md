# M49 新任务上验证强制干预与可达信用的分离

依据 M47 在已知 ARC/CommonsenseQA 数据的开发结果，单次验证 SciQ 官方训练分片中新取 256 个题目。每道题有真实研究材料，只有来源 A 可以看见；中继 B 与 R 都不见材料。主臂提供真实材料，次臂无材料、同题长相近的异题材料。所有模型、题目、选项顺序与下游提示严格配对。按公开盐与规范题面摘要取样，仅保留有20至200词材料、选项唯一、选择的材料互异、未出现在本周期先前选择题面板的题。用题与选项文本摘要定顺序，不按黄金位置排序。异题材料按长度分组相邻无放回配对。受限A-D输出，不能推论到自由中继。256题与此前数据分离，AU阈值、预算曲线与成功标准在读取本轮模型预测前固定。

三模型为 Qwen2.5-3B、Mistral-7B、Qwen2.5-Coder-7B；角色三种预定循环 (来源,中继,终端)=(0,1,2),(1,2,0),(2,0,1)。三款检查点来自两个架构家族。对同一内部边，记录每个强制来源取值的条件信用 e_a，与自然 K、实际 C、全 CPT 直径、均匀来源与源模型更换实验的对应量。主要确认条件沿用 M47：真实材料下每个角色排列均有至少 5% 且至少6道不同题，满足自然 K≤.01 但是有某种强制值使实际终端条件信用绝对值≥.10。典型正负例分别计数，正确/错误强制建议分别记录，估计这些强制值被实际自然源生成的总质量。另报告反例与模型天然无响应的题；该实验不推翻 CAPE 对压力干预的定义。

实际研究任务是分配复检预算：旧图仅看 B，新图也看 A，实际准确率净增益阈值为 .01。比较不复检、种子固定的16个随机顺序、最大中继行变化（分布无关）、历史终端概率不确定性、旧信用离阈值远近，以及基于实际来源分布的最坏删留遗憾。所有方法共用上游和旧读出的启动查询（按实际长度计），新检查一题获得16个新终端条件的完整反馈。在 0、10%、25%、50%、100% 的可变 token 预算下跳过超额候选，按题实价扣款；有保证时直接删除的操作对所有主动策略都提供，另列单纯沿用旧信用。风险优先度除以新复检 token；若旧策略保持，遗憾界为 K+.01，否则为 max(K−.01,0)。报告完整服务正确概率、误编辑与效用遗憾。算法主张另要求在 25% 预算、三个排列均优于最强预设非随机对照，并相对随机少至少 10% 遗憾；样本过易或没有可修错误视为不支持。排序实验为受限反馈重放，真实宏观成本以完整采集账为准。不得用其他预算点或对照臂补过。硬件上限3 GPU小时，全局160。目标为独立验证测量机制和作用边界。
