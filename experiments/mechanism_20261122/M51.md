# M51 固定查询接口下的最低证明成本

M46 加入强化 nested 与 unpriced 后，联合策略在四单元中的优势只在约两个百分点以内且正负不一致。M51 检验是否因为已接近任何策略的最低成本。固定来源与无建议中继已经查询且计费。其余的四个中继条件、十六个终端条件允许以任意顺序查询，允许先看终端再付费查询中继。原有调度器的行优先依赖不能当作理论下限。

每行有32种观察方案：是否已知中继分布，以及观察了四个终端条件的哪个子集。对每个可能的答案，用该方案求所有未测条件的最小、最大带符号贡献。未知中继行可取概率单纯形任一点，固定某个极点后，未测终端对某个答案的指示可分别取0、1。最大最小在极点达到。四行的界相加。指定黄金标签时只需它的信用方向已定；无黄金时，所有实际出现的答案以及一个代表任意新答案的类都必须有一致的方向。为反驳一个全标签证明，只需要某个标签的一种可行补全，不必同时实现各标签的极值。常数初始化均计，后续成本按每个查询在固定全表内的实际 token。两个两行组合逐一搜索，按成本剪去已不可能改善可行上界的组合；对4行等价于完整搜索至多32的4次方种方案。处理浮点边界使用保守容差并验证可行证书。该事后最短证书使用了未买的真实值，只作下界，不能作为在线策略。允许任意具有相同真实输出的补全，不能外推到另有已知语言模型参数结构的算法。

对 M46 已知数据作开发诊断，用作者数值解析；M50 未揭示、采用实际采集的完整表，是独立复核。分别报告黄金已知和全标签最低 token、已注册值域内最强盲策略与全标签下界的距离、零未测错检。若两个数据面板每个模型的最强盲策略含启动成本均不超过全标签下限的 1.10 倍，才称在该范围内剩余调度算法空间较小。若更大，报告尚可改进的空间而不声称有算法已达到下界。经典前例是随机阈值验证与最小覆盖背包 [Deshpande 等](https://doi.org/10.1145/2876506)。研究主张需依赖机制实证，不将证书复杂度本身列为新发明。
