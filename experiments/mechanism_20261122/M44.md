# M44 读出改变后是否必须逐个重测全部接收条件

研究从描述机制进入有明确适用范围的信用复检算法。只使用 M38 的已曝光开发数据。限定上游离散语义消息、历史完整的来源和中继条件分布、审计题有参考答案、白盒终端能返回受限类别概率。干预把最终读出从仅 B 改为同时看到 A、B。中继边 A→B 的新信用是 16 个条件接收概率 r_ab 的加权和，权重 w_ab=s(a)[B(b|a)-B0(b)] 完全由改变前的上游决定。观察部分新条件后，已知项累加，未查正权重在 [0,w]，负权重在 [w,0]，得到无需分布假设的界。不同新提示的概率向量不施加跨提示约束时，对同一黄金类别此界是锐的。随机上游、下游近似概率、开放式词汇、交叉提示公理等情形必须另行分析。这是有限离散反馈的转用，不能宣称发明区间算术、重要抽样、弱导数或阈值证明。

任务为保持或删除中继边，保持要求新信用超过每题 0.01 的质量代价门限。包括该固定代价仅用于决策尺度，不能替代实际 token 开销。所有有证书的策略采用同一停止条件，观察的真实新接收概率只有在查询回调中可访问。基线是全查、随机次序（预设16个种子）、旧接收概率不确定性除以成本、按 |w|/成本最大化最坏界宽下降。新候选用已有历史接收概率填补未测项来预测当前删留方向，按每 token 预计向该方向阈值收缩的幅度排序，每次获取真实反馈后重算。它可能输给最坏界宽贪心，特别当新读出改变了多数预测排序。零付费旧信用、始终保持/删除也报告错误或遗憾，绝不把这些不保证正确的策略说成更昂贵。

每个任务×读者报告两种来源分配等权的真值判定一致性、停止调用数、包括来源和中继历史查询与旧接收器的十次初始化成本的完整 prompt+输出 token，并与 16 个新条件全查相比。每个新条件一次模型调用取全标签概率只计一次，成本按相应任务 tokenizer 实验输入长度加一步。历史建表全成本、GPU 真实采集成本、路径消费 token 与线上服务效用分别记账。候选门：每一单元与全查删留完全一致，含历史开销的 token 至少节省 20%，且相对最坏界宽策略再省 2%。通过仅构成开发信号，须新任务及外部机制基线复核。若只有最坏界宽方法有效，则将其保留为强基线。既有噪声来源干预与本轮决策任务的门不能互换。
