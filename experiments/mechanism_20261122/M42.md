# M42 最终读出范围会不会遮蔽内部中继边

M41 的布局共用效应开发门只通过 OpenBookQA 的两个读者。现在独立注册另一种实际部署干预。AgentPrune 提供 all connected 与 last connected 两种最终节点连接方式，直接运行发布代码中的纯连接方法、保留固定版本回执。公开算法已考虑不同读出，CAPE 已研究输出沿图传播。因此不能宣称首次提出这些概念。本实验比较在同一部署内，放开最终节点对原始消息的直接访问，将多大程度改变同一条内部边的信用。没有复现原论文的训练成绩。

只用 M38 已经曝光的开发表。三种角色为来源 A、中继 B、最终读者 R，A 与 B 使用不同模型，交叉两种分配；R 取两种模型。让 A 产生语义答案 a，B 在有/无内部边时分别依 B(b|a)、B0(b) 抽样，R 总能看到 b，能否也看到 a 由最终读出模式决定。四种图的所有条件分布都由原始网络前向实际测得。用相同角色提示比较 B 有无邻居。不同角色之间的条件采样使用独立噪声。单次局部 A–D 消息是明确的外推限制。

对给定 a 定义中继响应差向量 d_a=B(·|a)-B0(·)。两种读出的最终语义分布变化分别为 d_a R_b 和 d_a R_ab。按真实来源分布平均二者的 TV 得 T_last、T_all。由随机核收缩，二者均不能超过第一跳 TV；二者之间没有必然的序关系。质量层面，边的有符号信用改变恰等于对 a,b 加权的 d_a(b)[R(y|a,b)-R(y|b)]。无黄金的分布变化与有黄金的方向和幅度分别报告。若模型只机械重复上游、忽略一条路径，直达读出可能减弱中继；两条路径互补时亦可增强。

预注册开发判据按任务和最终读者分四单元，来源分配等权，保留两种分配细目。每个单元 T_all/T_last 至多 0.8，至少 5% 的题目×角色分配其有符号信用差绝对值超过 .01，且至少 3 道不同题支持。报告边的严格反向、跨死区、效用变更、原始两臂概率和反例比例。通过仅支持进一步独立测试。后续需要自由文本源、中继和最终答复、真实答对率及开销、公开接口相符的对照，不能用这个开发表替代。新增计费推理为零，原 M38 的 0.08955 GPU 小时复用。技术近邻：[AgentPrune](https://arxiv.org/abs/2410.02506)；[EMNLP CAPE](https://aclanthology.org/2025.emnlp-main.623/)；[G-Designer](https://proceedings.mlr.press/v267/zhang25cu.html)。
