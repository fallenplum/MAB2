# M60 服务答案选择器诊断

该候选在问题级训练集的 80/20 问题切分上训练。行选择特征只使用新图源分布、旧中继分布、旧图信用统计、编辑行位置和查询 token 价格。特征不使用待查询的新中继输出，也不使用 `changed_rows` 之外的答案标签信息。测试集按任务留出问题，报告三次随机种子。

| 任务 | 选择器答案准确率 | 最大不确定性 | 平均 token |
| --- | ---: | ---: | ---: |
| QASC | 26.98% | 26.98% | 99.17 vs 99.48 |
| SciQ | 59.66% | 62.32% | 89.22 vs 89.48 |
| Commonsense | 52.43% | 45.83% | 90.50 vs 90.75 |

结果显示，任务条件信号存在，但方向不稳定。Commonsense 上有一致的点值提升，SciQ 上下降，QASC 持平。该候选未达到跨任务稳健改进门，因此不晋升为主方法。它保留了一个可检验机制线索，即最终答案质量与信用决策集合恢复之间存在任务条件错配。

这是开发数据上的问题切分诊断，不是独立确认集，也没有将待查询的新中继输出输入选择器。
