# M59 同一图编辑的独立物理再现

M56 观察了真实上游删边的决策变化，M57 显示普通精确请求缓存可解释大部分逻辑节约。为核验部署，另取与 M56 不同的 144 道 QASC TRAIN 题且全部科学事实分离。三种检查点分别独立承担三种提示角色，不将异构角色结果移植到同模型结果。在同一块 A6000 上，以真实新模型调用分别完成只复用基础中继的冷审计、逐请求缓存命中、执行前用旧观测重算的审计，并对照同一问题真实运行的全表。所有方法承担同一实际买过的旧图审计和新来源费用。三方法在 18 个八题组交叉排列，六种排列重复三次，所有输入固定批宽8且按前缀或读出使用固定物理长度；空位重复最后一条查询且照计。每个配置的驻卡时间计入项目成本。

逐条件核对请求数、逻辑 token、物理槽位 token、墙钟和所有标签决定。预设所有检查点的旧与新决定都须逐题与全表相同，若出现差异，报告不同批次计算的实际不一致。将全部旧图和新图双阶段的成本及新图单阶段的成本并列。主要部署预测是相较共享基础中继的冷审计，两种缓存策略在至少两个检查点都能省下至少 20% 新阶段逻辑 token 和 10% 新阶段请求墙钟。要声称预先重算比已有精确缓存有独立实用优势，还需要在至少两个检查点的双阶段总墙钟和双阶段逻辑 token 都再减 5%，同一 GPU 独占的块另报。旧决策不动的误删误保按之后揭示的参考判定。所有不一致与负结果保留。最多新增 3 GPU 小时。
