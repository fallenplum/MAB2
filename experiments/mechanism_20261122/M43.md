# M43 直接可见的消息是同一次生成，还是同题独立生成

M42 开发门 3/4，不能作为普遍直接读出衰减的证据。新实验的主要干预是消息来源是否为同一次实现，直接消息在两条主臂中始终可见。该对照既保留实际输出长度的边际分布，又固定模型、问题、角色、读出图、源调用边际和下游指令。每题同一来源产生两个自由文本样本 A0,A1。B 在无消息、看到 A0、看到 A1 三种情况下贪心给出理由和建议。最终 R 贪心生成实际回答。对 i=0,1 分别比较 R(Ai,B(Ai)) 与 R(Ai,B0)；交叉对照用 R(A1-i,B(Ai)) 与 R(A1-i,B0)。两臂每条已产生的直接消息和转发消息等频出现。第三种只读 B 的臂为公开框架 last connected 式对照。共同固定提示下两次直接与交叉离线配对的无边平均正确率必须精确相同。配对样本可能给相同意见，应保留。在真实服务中交叉臂独立源调用另计，离线共享工件省去的调用不得混作线上免费。

官方训练来源 ARC-Challenge 与 CommonsenseQA 各 128 道新抽题；不同来源、两种模型（Qwen2.5-3B-Instruct 和 Mistral-7B-Instruct-v0.3）分别报告。两个模型各自组成同族团队，和 M42 的混合来源实验区分。抽样对既有 M38/M40 和已定位的历史任务缓存作规范文本去重。各题输入与标签分离，GPU 工作者只见题面。来源温度 0.8、top-p .95、48 token；中继贪心 48 token；终端自由生成 24 token。终端需以合法选项字母开头，允许 Markdown 加粗、括号、预先列出的常见引导词；另报告无法解析率，错误计为零分。答题效用是实际选项正确率。

主检验是同一来源实现被直送时，中继边改变最终所选选项的比例是否低于独立来源直送。令 D 为交叉臂的变选频率减同源臂的变选频率，按两个来源种子在题内平均。任一对无法解析时，主变选配对统一在同一题、同一种子、两臂的四个结果均可解析的共同支持上统计；各终端正确率则覆盖所有题。完整归因门要求每个任务的模型等权 D≥0.02、每个模型在两个任务均为正、四个单元各有至少 90% 共同支持。进一步要求每个任务至少 5% 的全体问题在两臂间出现中继边实际有符号信用差，才能声称影响正确性层的边评估。按题内而非排列或种子作独立单位，报告四个固定哈希分块。仍然允许观察反方向结果，但不改预注册结论。若通过仍须跨家族团队、独立下游决策与预算收益才可主张算法优越。

预留上限 2 GPU 小时，共 2 个独立模型实例；全局不超过 160 GPU 小时。统计相同来源和独立来源各自的实际前缀、生成、调用成本，原始自然语言留在私有盘。自然文本渠道使此比较超出分类核，但多选任务仍限制外推。近邻：CAPE、AgentPrune、Copies or Sources? 研究的因果传播、最终连接方式与证据来源均需承认。
