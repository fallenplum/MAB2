# HotpotQA answer-only evaluation support

This is engineering preparation. No benchmark examples were selected, scored or
generated by this change. Official validation and test are untouched. The
upstream scorer is pinned to commit 3635853403a8735609ee997664e1528f4480762a;
unmodified source and Apache-2.0 license are retained under upstream/. The dataset
has a separate CC-BY-SA-4.0 license. Attribution: Zhilin Yang, Peng Qi and Saizheng
Zhang (2018). The adapter is a rewrite with strict input and transport checks.

`answer_metrics` reproduces the official answer EM, F1, precision and recall.
`score_aggregate_node` treats a malformed message as missing prediction with zero
metrics; it never recovers an answer by examining gold. A valid empty string still
follows official string metric behavior. This transport decision is specific to
future HotpotQA experiments and does not modify any GSM8K score or prior result.
Supporting-fact and joint metrics require a different output task and are not
claimed here.

The collector accepts only id, question, context, type and level; rejects label
fields; preserves every document and sentence in source order; and does no
retrieval, evidence partition, support filtering or truncation. Future protocols
must preflight model token limits and group normalized duplicate questions before
sampling. There is no scientific admission or dataset-choice outcome in this
module.

Run `python -m unittest test_hotpot_support -v` here. Tests compare 2,006 synthetic
answer pairs against the actual pinned official function AST, verify Git blob
hashes and check transport failure, complete contexts and label exclusion.
