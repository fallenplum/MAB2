# R1 独立复算器

此包独立实现标量采购排序、信用更新、图编辑、随机策略精确期望、8 个 episode 的 bootstrap，以及完整逻辑成本。代码未导入 `r1_policy.py` 或 `r1_adapter.py`。已读正式实现以核对接口，算法根据冻结协议重写，因此这不是对实现内容盲法的审查。

当前验收状态：29 项合成检查通过；真实 R1 I/C/S 均未由此子任务读取，正式结果尚未复算。合成通过仅说明工程检查通过，不证明方法有效或实验完成。

## 已覆盖

- 独立从端点构造 8 个图 episode，验证 A/B、可编辑边排序和 dirty 标签。
- 重建 592 个策略副本，按物理边编号处理精确并列；C 只更新各副本购买的边，S 和未来成本均不参与采购或动作。
- 均匀基线穷举全部 6 或 15 个子集，各副本独立决策后等权平均；不把最佳子集当作随机基线。
- 36 个方法行、34 个对比、动作类型计数、8 个 episode 等权平均、固定种子 69173 的 10,000 次 bootstrap。分位数使用独立标量线性插值，随机索引仍采用协议指定的 NumPy 生成器。
- 每副本、每 episode 和全体平均的实际 input/output token、调用数、评分数与评分 CPU 时间；与保守总 token cap 和评分配额核对。
- 完整 no-change candidate/no-graph 恒等性；未选择的 S 槽允许 NaN，已选择槽缺失则拒绝复算。
- 正式评分完成后，对照采购冻结文件、动作冻结文件、公开汇总和逐副本成本。任何实际排序或动作差异均判失败，不事后放宽并列规则。

## 使用

先运行合成检查：

```powershell
python .\test_independent_replay.py
```

仅在正式评分输出包含 `private/COMPLETE.json` 后，由主任务运行：

```powershell
python .\independent_r1_replay.py --analysis-dir <正式分析输出目录> --output <新审计JSON路径>
```

`--analysis-dir` 是同时含 `private` 与 `public` 的目录。复算器先核 COMPLETE 状态及 public 结果哈希，再核采购/动作冻结文件、payload digest 和 NPZ 哈希，最后才解析 NPZ。沿用已有完成凭据，不增加人工授权要求。目标审计文件已存在时拒绝覆盖。

## 边界

本复算验证已导出的数组、动作和统计的一致性，不读取原题或 gold，不重跑评分器，不验证 GPU 原始执行轨迹。实际 GPU 占用及历史失败成本仍需主任务总账合并。缓存共享产生的物理研究成本与各策略逻辑部署成本必须分别报告。

8 个 episode 的 percentile 区间只是探索性开发统计，随机子集副本、种子和同 episode 的服务题不能扩大独立 episode 数量。正式复算通过不构成独立科学确认，也不改变 R1 的冻结推进门。

数值容差：指标和区间绝对/相对 `1e-12`；成本绝对 `1e-8`、相对 `1e-12`。离散计划、动作、权重和协议绑定要求严格一致。成本较大的量采用浮点相对容差时，其允许绝对误差可能超过 `1e-8`；原始调用/评分数组仍按整数配额直接校验。
