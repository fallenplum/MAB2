# R3 有限银行验证的必要条件诊断 v1

本诊断只筛选研究投入空间，不是正式候选，不增加 GPU 调用，不使用 R1 S。
在真实 I/C 导出释放之前提交。R1 和 R2 的协议、门槛与分析完全不变。

## 问题与边界

在已付费旧图 A 的 N=12 题完整银行上，图变为 B 后，是否存在明显节省
验证成本的顺序，使当前银行的最佳单边动作获得严格的确定性证书？
旧银行只提供优先级，不作为新 B 质量的确定值。所有 N 题始终等权。
动作0为保持，1..6为物理边升序；相同银行质量选择编号较小动作。
证书仅确认这个有限银行的最佳动作，不保证未来题准确率或总体信用。

数据严格复用 R2 的16字段 I/C NPZ 和其完整验证器。只消费 C_A_quality、
C_B_quality、dirty及必要的身份字段；不读取 S、原题、答案文本。
完整 C_B 只在 oracle 和隔离反馈供应器中可见，策略通过购买得到单元结果。
R1动作冻结、原始审计和 R2 导出绑定先完成，才允许运行。

## 数学定义

每个新银行单元 Q[q,a]属于{0,1}，未揭示区间[0,1]。
L[a]=已揭示正确数，U[a]=L[a]+未揭示数，均以计数计算避免浮点歧义。
动作j可获证书，当对每个l!=j有 L[j]>=U[l]+1[l<j]。
这是对所有未知二值补全都成立的充要比较条件；不是置信区间。

使用先前合成执行枚举验证过的结构调用模型：每题非空集合通常支付3个
共同前缀节点；B基础聚合器成本1；干净边聚合器1；dirty边额外接收者1。
若某题只请求一个dirty边且不请求B基础，接收者基础版本无需计算，减1。
C(Z)=sum_q {3*1[非空]+sum_a z[q,a]*(1+dirty[a])−1[仅一个dirty单元]}，dirty[0]=0。
全银行成本12*(3+7+3)=156个结构调用；旧A银行252个结构调用另计。
该模型忽略实际输出汇合、token长度和异步调度。所有方法用完全相同模型。
不能把这里的成本直接声称为实测 token、GPU、延迟或最优真实缓存成本。
输出汇合可能改变最优顺序，因此本 oracle 只在本结构成本模型内是下界。

## 固定比较与 oracle

1. cheapest：单元最小当前增量成本，按(q,a)破同分。
2. random：256个独立均匀单元排列，seed=93173+1000*episode+replica；返回平均及范围。
3. gap_unit：用已揭示B值和未揭示位置的旧A值形成排序用点估计；leader为
   点估计最大者，challenger为其他动作中U最大者；在二者未揭示单元中
   选择增量成本最低者，按(q,a)破同分。界始终只来自合法已购B观测。
   若两者都已完整且尚无证书，则从仍有未知项的动作中按相同U规则选challenger。
4. gap_bundle：相同leader/challenger；每题构造二者尚未揭示单元的束，
   最大化揭示单元数/该束增量调用成本，按q破同分；束内全部付费揭示后停检。
5. oracle：已知完整B，仅作不可部署上限。对真实银行最佳动作w，以二元
   z、每题prefix变量和singleton-dirty减价变量解精确MILP，最小化C(Z)，约束上述证书。要求整数解、
   相同证书的直接重算、solver成功及mip_gap=0；超时/不确定记INCONCLUSIVE。

所有策略从空的新B观测表开始，使用相同旧A银行和相同缓存式成本。
最终输出每episode完整已购序列（私有）、证书动作和总成本；全银行是参考。
这不是从baseline中挑选替代候选；gap_bundle是固定待筛候选，仅本诊断评分。

## 预先固定的投入门

必须全部满足，才进入“真实成本和新独立服务实验设计”，不会自动启动GPU：

- 8个episode全部验证通过，任何错误证书直接判实现无效，不得跳过该单元。
- 非保持的真实银行最优动作至少3/8；否则保持图本身已解释大部空间。
- oracle平均结构成本 / min(cheapest平均, random平均, gap_unit平均) <=0.80。
- gap_bundle平均结构成本 / min(cheapest平均, random平均, gap_unit平均) <=0.90。
- gap_bundle成本不高于gap_unit的episode至少6/8。
- 加入相同252调用旧银行后的平均总成本比 <=0.97。

失败只淘汰这个“有限银行精确证书＋束验证”实现；不终止项目。
门通过也不支持系统质量收益、算法新颖性、ACL水平或未来服务改善。
不对8个对称图模板做确认性显著性检验；报告每episode，零分母视实现错误。
不通过后不得修改本次门槛或从其他策略改选winner；新假设需新协议。

## 优势、风险与相关工作

优势：不依赖精确信用预测；能先否定没有足够成本空间的实现；未知项不丢弃。
风险：小银行会接近穷举才获证书，银行最佳动作可能过拟合，结构费用不是实测费用。
ActiveEvidence (arXiv:2610.20532v2)、C3 (2603.06859v4)、EvoSteer
(2609.38661v2) 已限制主动证书、反事实重放和配对验证的独立新颖性。
本诊断不宣称标准MILP、branch-and-bound、gap选择或集合并集费用首次提出。

正式轮数变化0，GPU小时变化0。CPU、代码与输入哈希独立记录。
