# 闭账后的固定报告范围

状态：真实答案和质量结果开放前的报告准备。该文件不修改已冻结科学合同、统计方法、成本比较、选择或判据，不增设可让候选通过的指标。

首先原样报告四个主要EM对比、原Bonferroni bootstrap区间、有效支持数、L1/L2及绝对成本前沿结论。B仍是唯一通信候选；A、F1、单个seed、单条edge和任何长度分组都不能用作救援。输入溢出按原规则保留，基础设施不完整不评分。区间是近似bootstrap，不宣传有限样本精确覆盖。

全量绑定评分后，补充以下描述性核查，全部条件均显示，无择优省略：

1. 按11个条件报告严格EM、F1、aggregate格式失败数及生成结束原因计数。它们帮助区分格式/截断问题与答案错误，不允许从原始文本补抽答案改变分数。
2. 对两个seed分别报告A/B条件信用的负、零、正支持数及delta分布；同时保留跨seed乘积为负的结果。所有题按原选择次序、全部边等权，不挑受益子集。
3. 完整服务逻辑成本按方法与模型列示调用、输入/输出token、CUDA事件时间。物理研究调用、缓存节约、驻留、初始化、等待及失败费用另列，禁止互换费用定义。独立12基线匹配调用数与模型分配，不声称token或设备时间严格相同。
4. 如需解释容量/格式错误，允许用固定长度层的计数作描述，不增设显著性检验、不据其过滤题目或训练新规则。任何查看出的新假设只记为已揭示开发观察，未来须独立数据确认。
5. 可绘制主要对比区间、条件信用支持分布及完整成本比较图。图只读取已固定结果表；不得用调整坐标、删除负结果或选种子改变结论。

报告须明确：即使适用性门通过，也仅支持在独立新合同下研究复检机制，不证明主动采集比随机更好，不证明异构模型具有因果优势，不等于ACL论文证据齐备。若失败，冻结对应路线并继续外循环；项目级停止仍适用总合同。

优势是提前区分主结论和解释性诊断，并让格式与费用问题可核查。风险是这些描述不能定位全部错误的因果来源；两个seed不足以代表全部采样变化，单一任务也不支持普遍系统结论。
