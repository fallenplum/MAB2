# 作者侧审查

这份审查由同一研究流程组织，使用第二套独立编写的逐项计分程序。没有外部人类审稿。利益关系为参与了方法的实现、实验和写作。主要能力边界是程序复现及量化对照，稿件仍需作者核实贡献、数据许可、披露和最终文字。审查对照了 [ARR 责任研究清单](https://aclrollingreview.org/responsibleNLPresearch/)。

| 可能影响结论的问题 | 核查与处置 |
| --- | --- |
| 迭代是否把已曝光题变成了独立测试 | D29/D30 仅使用已曝光 APPS；D32 为训练文章；D33 为公开验证缓存；D34 为第五轮既有服务结果；D35/D36 为 D16 已曝光 QA 问题。稿件区分每折动作冻结、私有隐藏用例及真正的新样本确认。 |
| 理想上界是否公平 | D35 允许逐评估折按冲击查看所有未来标签，平均每格约八题。只报告它为机会；D36 只有历史面板的已知标签，可购买模型输出。二者不得合并为同一指标。 |
| 强基线是否可节省初始化和探测费用 | D36 的保持、固定删边和无消息模型均按真实服务需求计费。D33 分列免费单模型与需要历史初始化的单模型。票据不能解释成人工时间或现金。 |
| 独立复算与实际部署是否区分 | 第二实现从 D16 的请求标识复建初始化、去重、抽样、校正、选图、服务正确性和配对结果，共 288 行、4346 项一致。本次没有取得独立队列上的有效方法复现。 |
| 对负结果是否过度归因 | 时间检索中 64 个文章组只有 46 个可定位两问证据，18 个缺失均保留；APPS 只有一道题有非零当前信用。前者不能代表所有文章，后者不能拟合反馈可靠率。D34 结构效应的两个冲击方向相反。 |
| 能否声称投稿或最优 | 当前只适合作为有范围的负结果工作稿。跨模型池、在线真实延迟、人工反馈价格、外部算法同预算完整复现及人类独立复核仍缺失。 |

判断置信度高的范围是冻结试验中的记录、比较和失败决定。对其他任务、预算、模型或反馈渠道的外推证据不足。论文明确披露了 scientific-writing 与 peer-review 使用的 [Scientific Agent Skills](https://arxiv.org/abs/2609.00065)。
