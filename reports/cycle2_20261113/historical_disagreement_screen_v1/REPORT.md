## 输入和信息隔离

使用已有旧 G2 train200/tune80 派生缓存；没有重扫原始模型生成，没有读取当前 Hotpot、旧 R1 S、题文或 gold。D2 容器还有120个 excluded 题，只用于 partition/row 索引排除；质量成员通过选定行流式解码，未解释这些 excluded 题质量。数据 SHA 与此前独立复核、格式扫描的固定来源一致。

Z 仅用 seed2701 四个 r1 的 parsed answer **字面字符串哈希**；任一格式失败或空串为 unknown。它不是数值、语义或置信度一致性。其余2702–2705四 seed 用于 θ 六项交叉乘积。原两 anchor 随题变化；D 仅表示 receiver 的其他入边变化，不能把 D=0 解释成没有任何下游影响。

## 固定主对比

对每题先求有/无 receiver 入边变化两类边的 θ 均值之差，再比较 Z=1 与 Z=0 两组题均值。θ 是跨 seed 估计的**题×边平均信用漂移平方**，允许负估计。结果不是 EM 百分点、单次信用非零率、删留错误率或旧 G2 风险。

| 项目 | train：描述 | tune：唯一主对比 |
|---|---:|---:|
| 全部题数 | 200 | 80 |
| Z unknown / 一致 / 分歧 | 48 / 42 / 110 | 18 / 16 / 46 |
| 同时有 D=0/D=1 的题数（含unknown） | 155 | 64 |
| 可比的一致 / 分歧题数 | 31 / 85 | **13 / 37** |
| θ 差中差点值 | −0.0139483 | +0.00672193 |
| 2,000次题级95% percentile区间 | [−0.0337973, +0.00267864] | [−0.0256698, +0.0398324] |
| 预定支持 guard | 通过；区间跨零 | **未通过：一致组13<20** |

tune 区间仅按协议作为描述输出；支持 guard 未过，不能借正点估计授予进阶。train 与 tune 点方向不同，且区间均跨零，也不构成稳定支持。20/组只是最低报告条件，不是达到检验力的保证；没有增加数据来跨过这个门。

所有未知题和 θ 负值均保留。train 的2400个题×边 θ cell中89负、2188零、123正；tune的960个cell中49负、854零、57正。零交叉乘积估计不等于真实信用无变化；这些相关cell也不是独立样本数。

## 能说和不能说的结论

本次完成了可执行的低成本拒绝筛查：固定字面 proxy 在主要开发子集没有足够可比的一致题，不能据它提名新GPU策略。它没有把 H1 全部证伪，也没有测试语义分歧、条件动作错误或真实主动采集收益；这些信息并不在现有匿名 hash 中，不能在结果后恢复或换定义继续搜索。

同题不同 seed 的独立性属于 RNG/解码假设；seed 数少、图背景按题变化、开发数据已揭示、题级 bootstrap 近似都限制推断。θ 平方漂移关联不是因果中介效应，不说明哪个删留动作好，更不说明新反馈能以完整费用改善未来服务。

优势是无需新调用或 raw 扫描便能发现支持瓶颈，且没有从固定 proxy 失败切换到更复杂特征。风险是字面格式可能混合表示差异，单一 reference seed 只能测这一固定 noisy proxy；这些风险解释适用范围，不授权事后改协议。

对输入绑定、算术和按原 guard 停止的判断置信度高；对所有潜在 disagreement 信号不存在的判断没有证据。当前 Hotpot 仍按自己的合同继续，本报告不改变其门或后续主题的研究范围。
