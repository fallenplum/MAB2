## 失败诊断与成本

格式失败共59/4224。B为2/384，INDEPENDENT12为3/384，SINGLE_M为44/384。作为解封后的确定性算术界，即使B的两个格式失败都改成正确，最多增加2题，仍不能解释它相对INDEPENDENT12少26个正确答案的差距；这不是重评分或新显著性结论。SINGLE_M的格式负担提示未来中央单模型基线应单独验证输出格式，不能把其旧弱点继承为候选优势。旧分数不改。全部aggregate记录eos也不代表格式成功。

正式采集实际驻留32.578573 GPUh；含已单独收费的qualification，本候选共32.756922 GPUh。物理返回33,408次，完整逻辑服务50,304次，缓存复用避免16,896次新请求；没有把逻辑费用再次计入物理预算。未分解驻留余额2638.383秒不称精确等待。全周期累计47.225822/160 GPUh，保留0，余112.774178 GPUh；正式候选2/5，剩3轮。旧G1/G2历史费用未重计入这160小时账，整个历史项目成本仍有已披露未知项。

优势是保留强同调用/同模型配额基线、全题覆盖、冻结统计与可核费用。风险是单任务、固定图/算子和两seed限制外推，稀疏信用使变化规模仍不确定；本轮不能支持ACL级正方法论文。
