# 历史付费接收者分阶段筛查

**决策：不推进当前“冷启动、逐行均匀探测、按两种响应字符串层决定是否完成”的具体实例。** 使用记录 token 的逻辑账并按探测触达支付基图时，评分等价比 0 和 0.1 的 oracle 最优退化为全部完成。保留基图已不可避免地建成的边际情境，以及高评分代价假设下的微弱空间；它们没有证明真实完整成本收益，也不改变当前实例的淘汰。置信度：指定设计类内结论高，真实 GPU/部署收益未知。

这是事后历史 optimistic oracle screen。仅处理旧 train200/tune80 的 33,600 条匿名派生行，没有新推理、GPU、正式轮次、原题、新 R1 或官方测试访问。先固定 PROTOCOL.json，后检查数组schema，再固定成本补充说明，最后计算。所用真方差与真二阶矩是 oracle 信息，不是可部署策略权限。

## 问题与比较单位

目标是固定有限银行里 on-minus-off 二元终端质量信用的等权行均值。每行包含题、anchor、边、seed；它们不是相互独立的新题。这里给的是抽样设计方差，不是总体新题置信区间，不是逐边排序、最优图识别或未来服务效用。

所有方法均在付费生成 receiver 后识别 exact-wire coalescence；同 wire 的 aggregate 免生成且信用结构性为零。parsed answer 字符串不变仍可能产生非零信用，不能跳过或解释为语义不变。比较包括：直接随机 SRS、直接 Poisson、完整 census、全银行付费探测再 Neyman 分配、部分均匀探测再分层随机完成的 HT oracle。

这些是历史 input+output token，不是 GPU 秒、货币或 wall-time。缓存缺少 call_id/reused，不能重建实际物理执行与跨图复用费用。上表的基图按 distinct (left graph,seed) 支付一次完整9节点逻辑账；所有策略相同。另计评分等价成本 0、0.1、1 倍该 split 平均 aggregate token，后两者明确是假设，零也不是实测免费。receiver/aggregate=0.5、1、2 的常数单位情景另列在 FRONTIER.csv，与实测异质 token 不混合。

right/left 重合不是允许策略免费读取未购买反事实的理由。合同区分物理缓存与逻辑观察。若未来允许跨图状态购买后的合法复用，就必须为所有方法同时重建 action space 与完整费用；本表不能当作那个执行器的最优物理成本。

## 边际有利，按需基图完整逻辑账无筛选收益

下表为 tune，分子分母同一预算，均使用相同 exact-wire cache。suffix 行的预算比例以 suffix census 为分母；lazy 行以基图加 suffix census 为分母，两个横轴不能互换。

| 成本口径 | 预算比例 | 两阶段 oracle /直接 SRS 方差 | 全探测 Neyman /直接 SRS 方差 |
|---|---:|---:|---:|
| 仅 suffix，基图预付不计 | 10% | 0.97185 | 不可行 |
| 仅 suffix，基图预付不计 | 50% | 0.94939 | 11.89128 |
| 仅 suffix，基图预付不计 | 90% | 0.74727 | 0.75927 |
| lazy 基图+suffix，评分取零 | 10% | 0.99984 | 不可行 |
| lazy 基图+suffix，评分取零 | 50% | 0.99992 | 不可行 |
| lazy 基图+suffix，评分取零 | 90% | 0.99992 | 8.42047 |

**lazy 的 0.9998 不是响应筛选提升。** 此时两个完成概率均为 1，策略与直接 Poisson 完全相同；与 SRS 的微差来自设计及期望基图触达成本差异。train 同样退化；其相对 SRS 略大于1。对相同直接 Poisson 的方差比在数值精度内为1。

cost×variance 的完整前沿共 1,248 行，含每个方法、假设、split、预算和相对两种直接随机对照的比值。例：tune 50% suffix 预算，直接 SRS 的 C×V=34.3516、stage=32.6132；50% lazy 完整逻辑预算分别123.8557、123.8454，后者策略已经相同于直接 Poisson，不能把这点差异解释成方法收益。完整 census 的有限银行设计方差为零，是共同参照，不是新题总体零误差。

**不能删掉的反例：** 评分等价比=1 时，90% lazy 完整逻辑预算下确有微弱非平凡 oracle 配置：train p1=0.94813、相对 SRS 方差0.99721；tune p1=0.96805、比值0.99881，p2均为1。这是假设评分费用很高时的敏感性结果，尚无实测评分费支持。不能声称所有 lazy 成本情境严格零收益。

## 数学边界与独立检查

SRS 使用有限总体修正；全探测 Neyman 用真实层方差做连续受限配置；两阶段独立 HT 用真实二阶矩。所有预算是期望预算、样本量允许连续放松，不是硬上限执行承诺。真实 token 会随机变化；不能按预算停止后继续沿用独立 Bernoulli 纳入概率。

对当前两层独立 Poisson+均匀探测类，已额外证明一个充分条件：基图 lazy 边际费的下界足以抵消偏向完成高风险层的收益时，所有正预算的最优均为 p1=p2=1。两 split 的评分比0、0.1均满足。详见 MATHEMATICAL_NOTE.md。这是特定设计类、特定逻辑成本的证书，不是全部自适应策略的上界，不排除分组抽样、购买前异质配置或其他协变量。

验证包括56个小总体 SRS 子集穷举、Neyman/HT 与独立 SLSQP 的数值一致、lazy 优化129点网格与局部细化、census方差零、原类别计数与token列逐元素复算。独立代理核对了公式、初版输出与退化证书；它没有重新访问源数据。审查细节与限制见 INDEPENDENT_MATH_REVIEW.md。

## 优势、风险与后续边界

优势：完整收取 receiver 费用；强随机对照共享缓存；基图可按需建设；保留不利结果和高评分代价反例。风险：有限银行 scalar 目标弱于实际图选择目标；真方差不可提前知；物理缓存与评分/GPU费用未知；历史 oracle 不能确认未来收益。

Neyman、HT、filtered feedback、AIPW 和多精度识别均已有方法。未知 proxy 偏差不能直接套用已知 fidelity bias 的保证。当前没有原创方法或未来服务提升主张。文献核对在 LITERATURE.md。
