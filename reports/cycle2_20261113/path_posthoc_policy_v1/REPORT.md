# 已暴露数据上的分离 I/C/S 决策诊断

这是第三轮 96 题的事后开发诊断，不是新的独立实验，也不是正式候选成功。每个固定划分使用互斥的 32 题初始化、32 题反馈、32 题服务；初始化和反馈用生成种子一，服务用生成种子二。五次划分彼此重叠，不能当五个独立数据集或复现实验。随机策略执行 20 个策略随机种子；没有 bootstrap、区间或显著性推断。

图变化驱动的受影响边复检在 4、8、16、32 次配对反馈下，五划分平均服务正确率均为 30.00%。零新增反馈的受影响路径保护也是 30.00%；同样需要初始信用，因此它的初始化费用完整计入。32 次随机复检平均 28.625%，普通不确定性复检 28.75%。这些是同反馈对数诊断，**没有实施相同完整成本硬上限**，不能声称同成本优势。

无需初始信用的固定“删除另一条边”规则为 32.50%；单次 Qwen 为 48.125%，独立三路 Mistral 聚合为 56.25%。受影响边复检 32 对的平均完整费用为 443,196.2 tokens，路径保护为 298,457.2 tokens，固定删除另一条边为 70,399.0 tokens，单次 Qwen 为 48,270.6 tokens。不能把复检前置费用摊到一个事后无限延长的服务期。

**诊断结论：这个简单受影响边复检器没有展示超越免费结构保护的额外服务价值。** 优势是把旧信用、复检和未来服务的对象隔离，并显式计算未使用反馈不可免费暴露的选择过程。风险是小服务块、高种子波动、划分复用、只测试二选一删边，以及全档案已暴露；本诊断仅用于拒绝盲目扩展该简单规则。没有改变第三轮的机制筛选通过结论，也没有宣告项目停止。
