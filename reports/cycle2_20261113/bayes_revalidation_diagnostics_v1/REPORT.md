# 逐次贝叶斯采集的两次有界开发筛查

数据仅为已开放 R1 的 I/C 派生数组；NPZ 只加载 I_delta、C_delta、dirty，不加载 S_quality 或 S_cost。每 episode 的 C 前 6 题用于按反馈逐次选边，后 6 题只在动作确定后用于开发评价。两块均已被旧研究暴露，不能称新独立确认。8 个 episode、5 个固定采集随机种子，最多 24 次单格配对反馈。

第一次用 Dirichlet 三类信用均值及一步期望决策价值，图变化触及的边保留旧计数的 0.25，其他边保留全部；第二次用“旧证据有效/失效”两个后验的混合，依据每次新反馈更新有效性概率，初始有效概率分别为 0.5/0.9。第二次是该贝叶斯族本次 CPU 诊断的最后一次，不再扩大参数网格。

| 图变化条件 | 相对保持的开发动作增益 | 平均反馈对数 |
|---|---:|---:|
| 分数计数、图变化 EVSI | 0.0000 | 12.325 |
| 有效性混合、图变化 EVSI | 0.0000 | 16.375 |
| 旧证据全部保留的普通 EVSI | +0.0625 | 2.750 |
| 不新增反馈、保护被触及边 | +0.020833 | 0 |
| 保持当前图 | 0 | 0 |

完整无图变更、随机、方差、新鲜先验、无图混合、各 episode 和采集种子均保留。普通 EVSI 的正点估计是已曝光开发对照，不能替补为原方法的成功或独立确认。两个预定图条件方案均未体现优于免费保护的价值，因此没有新增 GPU 准入。

这里使用 24 次服务的假定时段及每反馈对 0.05 个正确答案等价成本；**它不是实测 token/GPU 成本，也不是相同完整预算的实验**。不能把以上数字解释为净服务收益或原始 S 准确率。初始化成本和实际配对闭包账必须在任何新正式协议中重新约束。

优势：反馈动作先于观测，失效判断可被新反馈纠正，并保留弃权与不采集对照。风险：图变化先验可能丢弃有价值旧信息、放大稀疏采样噪声；仅 6 题开发评价块及已曝光数据限制推断。结论是两个具体设计缺少扩展依据，不是所有贝叶斯更新或全部图条件维护都无效。无区间、无 bootstrap、无新模型推理。
