# 两个有界后续问题：提案，非准入

所有符号和建议均在当前正式 Hotpot 结果开放前写成；没有读取当前题目、生成或标签。这里不修改任何现行门，也不指定一个必须得到正结果的新算法。

## H1：旧信用的失效是否有通信前可见的条件结构

**可证伪命题：** 全局信用可能混合相反的局部效应。对相同图变化，通信前已生成的四个 r1 答案是否一致这一固定二分层，可能提供“旧删留方向在新图中会错误”的增量信息，超过图结构信号或一般难度信号本身。

### 估计对象与合法信息

令 Z 是 peer 通信发生前、四个 r1 独立 worker 的规范化答案是否存在分歧。仅用冻结 parser 的回答字符串及预先固定 normalizer；不得调用额外 judge，不读 gold，不使用 B-e 的 receiver/aggregate 答案差。格式无效必须单列支持数，不能在看效果后并入最有利组。Z 来自处理前的共享前缀，不是以干预后的输出分层，因此不会把后处理变量误称预处理协变量。

定义有符号存在信用 c_e(g,z)=E[Y(g+e)−Y(g−e)|Z=z]，及 d_e(z)=c_e(g_1,z)−c_e(g_0,z)。真正关心的是旧图信用按固定阈值作删留时，在新图的**错误动作及其损失**，不是 |d|、答案改变率或全局 MSE。完整条件对比包括：d_e(1)−d_e(0)，以及固定策略的未来损失。两者不能互相代替。

同模型、提示、seed 下 r1 与 peer graph 无关，才能共享它；若未来执行器不满足该性质，重新核算。单模型便宜参照没有义务替复杂方法支付四次前缀费用。共享前缀在同架构方法间只按实际支付记账，不能把既有部署最优基线也假设为有免费四代理输出。

### 最低成本反证

只建议一次旧开发 I/C 的 CPU 筛查，不读 S 来选规则、不生成新问题：预先固定 Z、一个图变化家族和一个模型端点一致的编辑家族；按题/episode 保持依赖，检查两组支持、格式异常比例、paired 信用噪声以及图×Z 对旧方向错误的增量。使用固定留组方式，禁止调 Z 的阈值、选最佳 prompt 或追加文本特征。

旧银行已揭示且 episode 少，只能作探索性拒绝筛查。某组缺少有效支持或区间过宽，应记“不确定”，不能称无交互，也不能因 oracle 分层好看即启动 GPU。若候选的相同 Z 信号在无图变化条件下同样有效，或 graph×Z 不增加独立预测/动作信息，应降为普通难度/内容条件化，不再主张 graph-conditional 维护。

### 后续最小独立实验及强对照

只有适用性和上述支持度具备后，才另拟一任务、一固定模型池、一图变化家族的 I/C/S 合同。I/C 学规则，S 只用处理前 Z 和已冻结规则，不读取 S 反馈来服务同题。对照至少包括：全局固定动作/不复检、仅 Z 的条件经验均值、仅图变化优先级、同反馈配额均匀选择、图×Z 的简单表。若使用序贯停止，再加同停止条件的通用验证基线。G-Designer/GTD 提供任务条件图优化近邻；若仅实现相同特征的简单受限对照，必须标明不是完整原论文复现。

只用一个低维表，不增加 GNN、Transformer 或判别大模型。对两个分层/多个编辑分别搜“最佳动作”需要训练预算与多重选择控制；不能把每题多个 seed/边当独立题。独立样本量须按期望动作差的可检测精度确定，不能将 64 题继续细分成多任务矩阵。

### 失败预测和创新边界

若 Z 主要反映所有模型共同的难题，反事实动作可能均无帮助；若通信效应极稀疏，分层会进一步增加方差；若条件动作收益只出现在已知 C，而冻结规则在新 S 不胜简单内容对照，则停止。仅发现条件交互不证明主动购买反馈值得；还须在相同完整成本下胜过均匀/周期。

任务条件图生成已有 G-Designer/GTD；本命题的新颖性不在“按内容选图”。尚待检验的狭窄问题是**处理前内容与图变化共同指示旧信用错误，是否值得新增复检**。这是低置信度候选，不是新颖性确认。旧 R2 的 β=1 residual transport 明确不在本方案中。

## H2：信用复检何时值得，何时应直接重学或不问

**可证伪命题：** 固定 k 的边选择把“有必要花反馈费”当作前提。图变化后旧信用只有在可用服务时段内带来足够改善，才可能抵偿复检；稀疏效应下，最优动作可能经常是不复检或使用通用直接验证。真正问题是是否存在可由历史信息预先识别的中间区域，让信用维护胜过这两端。

### 明确目标，避免任意折算

服务时段 H 必须来自实际应用需求或预先声明的固定实验情景，不能看结果后无限增大 H 摊薄成本。主比较需要预先定义合法目标：例如固定物理设备/时限内完成的正确回答数，或固定的质量约束与每模型完整资源向量。没有明确质量—资源交换率时，不把 EM 与 token 相减，不把 A6000 时间按未验证比例外推到别的模型/任务。

若只研究保质下的部署 token 节约，可报告费用维度的必要摊销条件：对任一固定成本维度，Δc_serv>0 时 H_break=C_feedback/Δc_serv；Δc_serv≤0 时这一维度没有回本。它不是准确率提升的货币价值，也不证明整体 Pareto 优势。当前固定三轮算子总计 13 个逻辑 calls，剪 peer 边主要影响输入 tokens，不能在此公式里虚构减少 worker 输出调用。

### 最便宜的反证与比较

先用已闭账旧报告中的完整费用量级和固定 H，写出乐观上界/最低反馈费；只作算术，不重扫旧 raw。若在预定有限时段内，即使乐观界也无可行质量—费用改善，则不实现新策略。若缺少可识别的质量上界或真实 H，结论是资源论证不足，不是算法失败。

若还有空间，再用旧开发银行做一次严格可见性 replay：不复检、直接均匀重新估计、均匀+同停止规则、普通不确定性/GAI/aLTT 风格验证、cost-aware baseline、旧信用只排序的同验证器。所有策略有相同停/弃权权限和合法缓存；不能让候选节省预算，却强迫随机用尽预算。旧信用只能排序或提供在训练折固定的先验，验证仍用新鲜随机反馈；不把偏选历史观测冒当 iid。

标准的 HT、控制变量、有限总体置信序列、aLTT、成本归一化不作为创新。跨边缓存/侧反馈会扩大 history，须满足正确条件抽样/鞅假设；既有 aLTT 官方 LLM 实现使用新的全局数据行，本项目未来扩展的潜在问题不能倒推为其论文有 bug。对有限银行控制的错误接受率不能自动变成未来分布、每题伤害或长期反复更新保证。

### 失败预测和停止

旧信用不比无信息排序好时，维护只增加初始化费用；图变化太频繁时来不及摊销；图效应很稀疏时合理策略应频繁不询问。若候选只比固定 k、强制全预算的弱对照好，不支持核心机制；若普通通用验证已达到同等收益，应报告应用证据，不再堆模块。

该问题与 R3 不同：不要求认证已揭示有限银行中的精确 winner，也不使用 gap_bundle 或离线 oracle 充当部署算法；以 future-service 的完整收益/成本为终点。但它与通用 VOI/Hidden Utility Bandit 高度重叠，新颖性置信度低。新 GPU 仍需另立资源与科学协议，且先过当前任务适用性；不因本提案自动占用剩余正式轮次。

## 共同停止规则

每条候选最多一次预先固定的旧开发 CPU 否定筛查；没有信号/支持不足时保留失败或不确定，不在同银行轮换特征、阈值或效用单位。能通过仅意味着可以讨论一轮独立实验，不能称已验证。当前 Hotpot 结果不进入这次筛查，也不用于候选排名；本文未选择题、执行筛查或启动任何新实验。
