## 具名统计轴与评分

顺序固定为选择清单 384 行、2 个明确 seed、`[A,B,A_MINUS_E,B_MINUS_E]`，不使用完成顺序或图名位置推断。实际 mask、题目指纹、边、seed 和协议身份逐层检查。独立 12 与单 M 的 aggregate 通过节点别名、槽位索引定位。

新增的不同人工标签哨兵逐一独立计算全部 3,072 个图 EM、全部 3,072 个图 F1，以及 1,152 个基线 EM；再从这些解析预期值计算四个主统计形式及四边分层均值，与输出一致。这里独立检查的是输入数组与统计量绑定；没有重新声称完成 bootstrap 覆盖率理论验证。

信用差为每题每 seed 的 `δ=(B−B_MINUS_E)−(A−A_MINUS_E)`，有符号指标先题内平均两 seed，平方信号代理为每题两 seed 乘积后平均。未把两个总体均值相乘。四主 EM、固定边分层、PCG64 种子与 `.00625/.99375` 分位保持冻结实现；F1 仅次要描述，不替换 EM 门。

新 Hotpot 的冻结规则为 `score_aggregate_node` 对规范化 `parsed.answer` 严格评分，`format_ok=false` 时 EM/F1 为零。独立测试在 S2 图 aggregate 放入与人工答案相同的原始生成文本但设置格式失败，结果仍为零；不承接旧 G2 的 raw-text fallback。INPUT_REJECTED 只按冻结容量失败规则置零保留题目；基础设施错误、缺条件与部分归档拒绝全批评分。

## 标签释放与归档权限

`evaluate_after_release` 在全部 384 题、4,224 终态及外部归档审核绑定成功后才调用标签回调。独立篡改最后一题的最后一个图 mask，同时为人工 fixture 重算外层文件哈希，仍被内部语义检查拒绝，且标签回调次数为零。审核缺失完整账本 scope、payload 增加答案字段、重复 JSON 键或非有限 JSON 数值均拒绝。

标签 vault 必须单独提供，原字节 SHA 与审核回执相同，且严格覆盖 384 个原始 ID。绑定后的嵌套对象修改会破坏语义 seal。外部预期审核 SHA 的信任来源是调用方责任；本模块不认证签署者，也不防范同 Python 进程内恶意改写程序。

## 完整费用与缓存

完整服务成本从每个逻辑节点重新累加，包含 reused 节点；graph 按 round-major、independent12 按 role-major 顺序，避免先前 JSON 键排序导致浮点重建顺序混淆。新增独立整数及 CUDA 加总验证：每个 S1 B/no-edge/independent12 的 Q/M 调用总数为 2,304/2,688，单 M 为 0/384；输入、输出及 CUDA event 费用与人工节点逐项公式一致，未以 physical cache 节省折扣完整服务成本。

容量溢出使对应完整服务费用未知，并令 frontier 不评估，未把未知填零；单 M 的 Q 成本因算子从不调用 Q 可证明为零。CUDA event 费用不等于驻留 GPU 小时，物理研究账仅保留独立审核 pins，不与逻辑服务费互换。

## 优势、风险与验收边界

优势是明确的具名轴、完整覆盖后释放标签、源与文件多级绑定，以及缓存后全逻辑服务费用重算。测试已覆盖内部语义篡改，不能仅靠更新文件 SHA 绕过这些已检验边界。

仍需外部真实归档审查完成模型/tokenizer 身份、逐请求 native/durable 输出、解析器与原始生成的一致性、cache 输入输出合法性、跨条件 call ID、所有尝试及驻留账本闭合。本适配器不会自行读取或重演这些独立证据；人工 fixture 的物理账摘要本身也不构成真实采集审计。选择 payload 与真实源投影的真实性仍依赖冻结选择、长度与 source 审核链。真实评分前必须由可信外部审核签发绑定完整归档的 release，不能将本报告直接用作该许可。

置信度：对本快照在所检验人工边界下的轴/评分/逻辑费/释放顺序为高；对尚不存在于本审查输入中的真实归档正确性不作判断。未发现阻断不等于证明所有输入均正确，亦不建立方法有效性。
