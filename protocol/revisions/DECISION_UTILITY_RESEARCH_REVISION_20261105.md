## 实验 A 的第一步 D1

### 固定的输入与计算规则

沿用既有 B0、C1、C2、PCA 与参数，读取原 G2 的两个锚图及全部单边切换输出。输入为 120 题、两锚图、12 条边、5 个生成种子。完整输入、源码和标签访问凭据分别记录哈希。

存在信用定义为 `F(mask1)−F(mask0)`。从当前锚图切换边的质量增益定义为 `(1−2m_e) × 存在信用`，区分当前边的开启与关闭状态。

本次决策只允许 stay 或单独切换一条边。每个模型选择严格正预测增益最大的边，同分按边索引从小到大确定，所有候选均非正则 stay。参照包含固定 stay 与对 13 个动作均匀随机选择的期望收益。该随机动作参照属于离线动作诊断。

| 指标 | 实现与解释 |
|---|---|
| 符号 | 五种子观测均值的负、零、正三类混淆与完整支持数 |
| 排序 | 每题每锚图内 12 条存在信用的 Spearman，平均秩处理并列，常量向量单列 undefined |
| 单步质量收益 | 根据冻结预测先选动作，再用完整观测菜单评价；先等权平均两锚图，再跨题平均 |
| 配对区间 | 10,000 次整题 bootstrap，种子 49173，保留所有负估计 |
| 观测 oracle | 在同一带噪观测菜单上取最大值，显式保留选择乐观偏差的说明 |
| 不确定性代理 | 原训练设计矩阵方向 leverage，及其对观测符号错误的识别排序 |

λ 固定为 0，D1 衡量质量层面的单次动作价值。现有菜单只覆盖锚图的一次切换。该计算不测完整预算净收益、多次连续编辑、主动复检收益或恢复轨迹。

五种子观测均值仍有噪声。符号和排序以观测代理为目标，真实信用的正负类别尚未被确定。观测 oracle 的最大值含选择偏差，不能作为真实后悔值的无偏参照。

### 不确定性诊断

对 C1/C2，以既有训练题和唯一图掩码重建 `X^T W X + alpha I`，沿用原每题总权重 1 与原选定 alpha。方向代理为 `sqrt(d^T (X^T W X + alpha I)^-1 d)`。矩阵构造不使用旧留出标签。

报告 leverage 与绝对观测均值残差的秩相关。仅在观测均值非零的坐标上，报告高 leverage 及小归一化 margin 对符号不一致的 ROC AUC、正负支持数。单一类别的 AUC 和常量向量的相关系数均保留为空值。B0 没有在本协议中定义对应的设计矩阵代理。

这些代理没有噪声标定或覆盖率保证。其识别目标也受到生成噪声影响，尚不能作为信用失效证书。

## 实验 A 的独立确认

D1 完成后，先依据全部开发诊断确定一个待验证的简单预测器或采集信号，再冻结独立确认合同。新合同必须登记以下内容。

- 题池资格、历史使用与暴露审计、去重规则、按题哈希抽样域、样本量及固定生成种子。
- 预测器架构、参数与特征版本，或仅使用保守反事实验证的机制。开发数据上的选择过程完整保留。
- 唯一主决策端点及主比较，效应阈值、题级统计方法、多个主比较的校正与停止规则。
- 删留净价值的成本单位与 λ，或明确限于质量诊断。阈值附近的定义在查看新标签前确定。
- 先冻结输出和预测，再由数据所有者有序释放标签。确认集不参与调参。

正的单步诊断可以提出后续假设。不确定性 AUC、整体 MSE 或任一局部组的结果均不单独构成 G3 新通行门。若预测器缺少决策信号，仍可另立协议检验弱先验加主动反事实验证，但其优于随机采集的主张必须独立验证。

## 实验 B 的共同初始化与各自反馈更新

“固定预测器”在主机制对照中指所有方法共用模型池、汇总器、特征、模型族、超参数、初始 checkpoint、初始化反馈、更新实现和图编辑器。各方法只接收其实际获准或付费取得的反馈，使用同一规则更新各自的 θ 与 V。由不同采集产生的参数轨迹属于被研究机制的一部分。

若研究全程冻结 θ 的版本，单列为不同实验，并明确哪些统计量仍可更新。静态信用参照也要精确区分存储旧图信用、冻结 θ 但在当前图重算，以及只禁止额外审计但允许正常到达反馈更新三种算子。

| 机制或消融 | 主要检验 |
|---|---|
| 存储旧信用、不额外复检 | 持续信用维护的必要性，冻结对象须明确 |
| 共同初始化后、当前图重算且无额外审计 | 图条件重算本身的作用 |
| 随机复检 | 额外反馈数量与主动选择的区别 |
| 固定周期复检 | 自适应时机的作用 |
| 仅时间陈旧度复检 | 图变化提供的额外信息 |
| 最大不确定性复检 | 决策相关方向的作用 |
| 决策相关采集、去掉图变化权重 | 图条件信用维护权重的增量作用 |
| 图变化与决策相关采集、去掉成本归一化 | 依赖执行成本的作用 |
| 完整方法 | 图变化、决策方向与新增执行成本共同作用 |

机制应以精确算子和观测权限区分。两个实现若在当前设置下给出相同选择，合并或作为退化现象报告。C1 的质量边信用在当前一阶工作模型下不随其他边变化，使用它时需检查图变化项是否退化。单纯换名称不能构成可辨识的消融。

额外参照包括每次全量重估、独立边均值、禁恢复、更多不同题单图评分。它们的成本和架构角色单列，主机制对照保持共同预测器。

## 完整预算与反馈顺序

所有方法共用流顺序、生成随机数规则、初始化费用、探索保底、总预算及每题正常服务保证。主图、候选反事实、购买评分动作和保守资源预留均在看到本题任何生成结果之前冻结。本题主服务结果在标签揭示前固定，到达的评分只用于未来问题的决策。

服务成本、额外执行成本和评分成本分别计量。购买单图反馈和购买成对反事实反馈按实际新增项目计费。跨策略共享离线算力只能减少研究执行费用，各策略的信息权限和模拟余额分别结算。

每个问题—图—执行版本的原始质量标签在回归中只进入一次。增加新种子后以预定规则替换聚合观测，保留追加审计历史。同题共享图和配对执行按相关块处理。

学习审计与隐藏评估分开授权。策略实际购买的学习审计标签可以在到达后更新其未来 θ 与 V。独立确认、误删及恢复诊断所用的隐藏评价标签只提供给评估器，不能作为策略的额外免费反馈。

硬预算需要对剩余正常服务预留可执行上界。现有接口尚缺独立报价与预留 API，实际输入 token 上限还须覆盖问题、上下文、序列化和 chat template。λ、预算、探索份额、流长、种子及停止规则在 B 的新合同冻结前补齐。

## 最终评价

主要比较完整预算下的服务质量与累计服务收益曲线，并报告所有方法实际回答题数。质量与预算的主比较、成本曲线面积规则和统计检验在 B 冻结前选定。至少对随机、周期与最大不确定性作直接机制比较，并预先处理多重比较。

机制评价报告误删、错误恢复、纠正率、到纠正的延迟和每次纠正成本。误删与有益恢复需要独立反事实审计，其采样权限和费用预先固定。冻结学习后，在独立测试集另测纯服务收益，并报告学习投入的可摊销范围。

## 优势与劣势（风险）

优势为研究目标重新对齐原方案，复用已有简单预测器与执行器，先验证决策信息，再隔离反馈采集机制。

风险为 D1 数据已知且噪声稀疏，单步收益可能无法推广到连续图编辑。设计矩阵代理可能只反映输入几何。若主策略与随机、周期和普通不确定性在相同完整预算下无可重复收益，核心创新仍缺乏实证支持。完整成本中的初始预处理、恢复及部分控制 CPU 时长缺失继续登记。

## 当前状态

原 G2 负门保持历史身份。D1 已完成固定配方的事后探索，完整结果见 `results/D1_DECISION_REPORT_20261105.md`。三个既有模型的单步质量增益区间均跨零，C2 的 leverage 识别观测符号错误 AUC 为 0.501338。当前结果尚未支持既有预测器的稳定质量决策收益。

后续候选可采用保守的反馈验证过程。共同预测器仅产生候选编辑，先用已完成服务的开发问题开展当前图上的付费成对审计，再依据预先定义的证据规则决定后续问题是否采用该编辑。图版本改变后，旧审计继续保留原图身份，暂停边保留共同探索机会。随机、周期与主动方法共用这一编辑接受算子，仅改变采集对象与时机。

该候选需要单独冻结审计块、证据规则、反馈延迟和完整预算。Ridge leverage 目前只承担排序代理。置信覆盖若进入编辑接受规则，应另行验证其统计条件或使用独立审计块。主服务结果在本题标签到达前固定，反馈用于未来问题。

新独立确认及 B 尚未启动，尚未形成新的正式通行结论。下一步先固定候选机制与独立确认合同，再采集新数据。
