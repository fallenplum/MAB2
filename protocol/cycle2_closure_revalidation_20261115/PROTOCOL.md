# 第五轮正式候选：闭包成本下的决策价值复检

精确定义、源码及数据哈希在 SCIENTIFIC_DESIGN_FROZEN_V1.json；冻结先于任何本轮正式模型调用。

640 个新开发题分为8个不相交 I8/C8/S64 episode，5个生成种子、9个配置。所有活动节点都能读取完整原始证据，所有策略共享无效节点跳过。提名 closure_EVSI 与普通 VOI 的关键区别是反馈已付费调用闭包的增量价格；与旧图成本消融的区别是当前图导致的删留成本阈值。初始统计、模型池、反馈接口和原始信息相同。

主效用为服务准确率减完整 I+C+S token 费用，权重固定为每千 tokens 0.005 个正确答案等价；这是声明的研究权衡，不是经济定价。必须同时报告原始准确率、费用、其他预定权重以及免费结构控制。共同完整上限可能不紧，不能声称实际开销相等；真正比较同时包含实付账和服务收益。

候选必须优于随机/周期/不确定性/旧信用/免费保护/普通 VOI 和无初始化固定控制，且满足单模型、投票、独立聚合质量与成本门。任何一项失败都按候选失败处理，不能改选其他方法。第5轮结束后已达到正式候选轮数上限，转最终审计与证据限定论文交付；不是因单个候选失败擅自停止。

优势：真实调用依赖改变费用的机制可检验；全部反馈在购买后可见，S不输入策略。风险：八个episode及单任务限制推断；普通VOI、免费控制可能解释全部收益；基准金标是理想化反馈；新颖性暂低。即使通过也只是开发筛选，正面论文还需要同一方法的独立确认、第二任务和复现。无置信区间、无bootstrap。
