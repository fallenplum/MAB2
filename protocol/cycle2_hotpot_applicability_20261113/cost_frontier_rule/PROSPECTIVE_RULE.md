# Hotpot applicability 的预先费用前沿规则

这是在真实384题尚未选择、推理或评分前，对候选合同 `cost_frontier_review` 的执行定义。原四个EM主统计、区间、支持度门和候选B均不变；不把 B−single 描述量升格为第五个显著性检验。原候选文件保留，冻结时另绑定本补充与代码SHA。

只比较 seed1 的 B、NO_EDGE、INDEPENDENT12、SINGLE_M，同一384题、所有终态完整且没有输入拒绝/基础设施失败。A、编辑后图、seed2及题内oracle不参加此筛选。EM使用精确成功数，不能以F1替换。若有输入拒绝、数据缺失、费用未知或尚未完成独立归档核验，状态为 NOT_ASSESSED；原合同本身另禁止容量失败触发机制升级。

每个方法按完整独立服务所需节点加总逻辑费用，缓存的生成也必须计入。向量为每个实际模型各自的 calls、input_tokens、output_tokens、CUDA_event_seconds，共8项；不能把Qwen和Mistral的token或GPU时间合成任意汇率权重。calls/tokens使用整数；CUDA事件秒为观测浮点且保留测量精度，不添加事后容忍带。

聚合账必须满足基本可实现性：某模型calls=0时其输入、输出和CUDA事件费用均为0；calls>0时input_tokens至少等于calls。显式unknown不得转换为0。输出tokens及计时允许非负的原始测量，不据此声称生成免费。这些字段检查不能替代原始事件与完整节点的来源审核。

若某一预定对照的成功数不低于B、上述8项全不高于B，且成功数或至少一项费用严格更优，则将B标为本次完整观测下 DOMINATED。否则为 NOT_DOMINATED。使用未舍入值，不以图上四舍五入值判断。

这只是**观测点的描述性Pareto筛查**，不是总体随机支配、等价或已控制家族误差的费用检验。NOT_DOMINATED 仅表示这组数据在所列向量上没有满足该严格支配条件的已列对照；不能解释成具有部署优势或完整净收益。DOMINATED也不是所有预算/其他分布上的不可行定理。每项原始观测与支配见证同时报告，不能只报告状态。

CUDA事件总和表示实际生成节点的计算测量；复用节点的逻辑费用引用其原付费生成记录。这不是一次独立 fresh 部署的整机墙钟/延迟测量。load-to-exit驻留、共享GPU争用、编排/I/O/等待、工程资格、盲前缀及失败费用计入另一个物理研究账，不能算作每个静态架构都实际付出的同一驻留成本，也不能被漏报。峰值显存和未知独立服务驻留另列，不用共载双模型时的峰值冒充singleM单独部署需求。各方法没有额外初始化/反馈训练费；如后续维护方法出现此费用，必须新合同完整计入，不能复用本静态筛选为其效率主张。

此筛查是原 `semantic_upgrade` 的一个保守描述性条件，不能救L1/L2失败、替换主候选或单独启动下一正式实验。新研究协议仍需独立证据和剩余预算。优势是不用任意token/GPU权重，完整计入缓存节点；风险是时间测量有共享硬件噪声，有限样本点前沿可能不稳定，维度多使NOT_DOMINATED容易出现。只据本轮前沿不能宣称系统成本最优。
