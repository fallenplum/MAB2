# D33 在真实小模型答复上复现可计算的终端图编辑

D32 的固定时间下换图造成 9 篇信用变化，但只有 1 篇有可纠正的决定。所有同行预算都覆盖全部五组成对分歧。另一个仍在 MAB2 范围内的机制是跨不同问题维护一次部署图的信用，避免重复购买同一问题已经暴露的答案。此处使用真实、既有的小模型答复；把上游节点的答复作为票，改变进入确定性终端的消息边。覆盖范围限于答案汇合，不含上游模型之间重新推理。开发成绩不能用于独立确认。

冻结 WinoGrande 官方验证划分在 LLMRouterBench 的六个缓存模型，按注册顺序 Llama-3.1-8B-Instruct、gemma-2-9b-it、granite-3.3-8b-instruct、glm-4-9b-chat、internlm3-8b-instruct、Qwen3-8B。此前只检查过分割、字段与编码。须逐题对齐题面与标签；空输出弃权，平票时采用列表中首个有效答复，所有弃权视为错误。连接相邻发布位置，并按规范词集 Jaccard ≥0.72 取连通分量；按题组固定分为历史、反馈池、服务三个轮换分区。所有模型预测为既有样本，三个种子仅改变采集顺序。公开验证缓存题目并非新独立确认集，分组也无法消除全部语义重复。

旧图基础为模型 0，新图基础为模型 4、5。可选动作均为不添边、添 1、添 2、添 3、全添 1/2/3。实际部署前固定一个动作，不读取当前服务题其他模型的票。每个复检方法共享历史区的六组答复与标签，候选反馈池的六组答复均按完整 token 计费。对当前图的不同动作作成对比较，以历史标注拟合的岭惩罚逻辑回归估计答案概率，再用 24 个标签的分层残差均值修正每个动作的估值。相同标签一次覆盖该问题的全部可计算图。分层基于当前是否存在决策分歧、旧/新相对动作变化、历史预测的不确定性。候选按预估方差、当前动作分歧数以及跨图动作移动量分配预算。固定的当前分歧分配去除最后一项，检验历史信息是否有边际价值。另比较统一随机、周期、通用不确定性、只用历史旧图、历史标签上直接重放新图、只用历史拟合而不采集、历史最佳单模型与直接 Qwen3。金标准上界允许免费按整个服务区选择单一固定编辑，只作机会界定。

决策以历史、反馈池、服务调用的总输入和输出 token 计价，每 token 扣 0.000005 效用，在该折实际服务量上摊销。历史与新增标签、既有日志货币成本、服务调用数单列。标签金钱价格未知；按零额外货币费用的有利假设计算候选完整 token 效用。无需前置调用的部署策略可跳过相应全池推理。成功要求三个采集种子相对最强同预算选择器的完整效用各至少提高 0.01，且每个种子均不低于最强低成本基线；失败保留所有折、种子、纠正与破坏数据。不用同一数据再挑模型、改收费或调门。没有增加 GPU 调用、重用封存集或扩展服务器权限。

来源与邻近算法包括 [LLMRouterBench 作者配置](https://github.com/ynulihao/LLMRouterBench/blob/main/config/baseline_config.yaml) 与 [Smoothie，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/e6b57a990462df5afa58d64ce2709db9-Abstract-Conference.html)。按模型答复估算质量已有先例，分层采样、重要性校正与多数投票均不能单独作为创新。
