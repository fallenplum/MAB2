# D30 可执行程序作为边消息的最后一次已曝光 APPS 机会检查

Formal10 的计划文本边缺少实际信用变化，D29 的修复/重采样选择只在两道题出现结果分歧。现在更换被传递的对象。小模型的独立可执行程序本身可以成为最终答案。检验另一个 3B 程序作为消息进入候选选择器时，一条其他输入边的消失会否改变它的条件信用。本诊断在查看混合程序组合的结果前冻结。该 16 题使用过多次，所有结论仅作探索。

C 为直接 7B 初稿，Q 为独立 3B 程序，B1、B2 为两个独立 7B 续采样，T1、T2 为原有 7B 反馈修复。每个策略只支付实际取得的请求、可见测试和必要前缀。首个程序通过两例即结束，否则选已取得程序中可见通过数最多者并按顺序破平。每个候选的隐藏成绩只在选定后读取。固定策略为 C/B1/B2、C/T1/T2、C/Q/B1、C/B1/Q、C/Q。另比较单次 C 和之前的 D29 规则。每次支付所有观察历史的成本。可实施规则在 C 两例全错时走 C/Q/B1，其余走 C/T1/T2。金标准上界免费预知五个固定策略的结果，以最高冻结效用选择。

被研究的边是 Q 到选择器。旧图顺序 C/B1/Q，新图 C/Q。两图分别删除 Q，按同样的停止和选择规则独立计算边信用。要求新图至少四个不同题的当前信用非零，且至少四个题存在跨图信用变化。沿用 D26 的效用差至少 0.02、质量差至少 −0.02，各种子相对 BOK3_EARLY、REPAIR3 和 D29 规则效用非负。公开全部对照和种子结果。已实际运行的两个单模型基线必须逐观测复现。

这是对两个求解模型和确定性选择器的回放。禁止用先前同题的完整已生成程序作为免费输入；相同可见候选应允许相同的缓存和复用。上界仅检验机会。若未过门，停止在这 16 题上搜索新策略，不再通过换顺序、改成本或改阈值推进同一数据集。后续新 GPU 研究需有不同的机制证据和可核查的新数据。
