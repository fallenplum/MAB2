# 分段试验的评分入口

正式收集分为两段。原段完整覆盖索引 0–5，两个工作进程按用户要求中止。续段必须完整覆盖 6–15 且四个工作进程正常退出。合并清单保留两段原始清单、退出码与实际驻留时间。逐题校验输入、种子、图变动、30 个条件、算子与物理模型请求，再按本机原 tokenizer 复核输入 token 数。覆盖验收通过后只释放 16 道 pilot 题的隐藏用例。

本机 WSL 的非特权 Linux 命名空间运行原 Python 3.8 用户态、可见执行适配器、系统调用限制与超时规则。隐藏执行器只替换两段收集的入口断言。质量计算、对照、固定效用、原始返回检查和 D26 的触发条件沿用冻结源。操作系统内核与服务器不同，人工语料重放用于检验返回值的一致性。计入效用的可见执行时间仍取自原 GPU 服务器工作进程。隐藏评分在本机执行，耗时单列。
