# D27 任务版本谱系的盲态可行性检查

当前 APPS 试验同时提供旧图和新图在同一问题上的输出。旧代码在当前问题上可直接复用。另一个可区分的机制问题是，外部任务需求变化之后，图拓扑变化是否还会带来额外的信用失效。任务版本和图版本必须独立交叉，保留语义不变的改写作为对照。程序复用、单模型修订、公开测试修复均需使用同等历史信息，全部重复调用按实际成本收费。

本次只检查成对任务能否从作者发布的显式谱系恢复。冻结原版 HumanEval 的 task_id 和 EvoEval v0.1.0 的 subtle、verbose、concise 三组文件。从压缩源逐行解析时只引用 task_id 与 parent 字段。核对每个父编号在原版是否存在，分别统计未识别条目、非一对一的父组，以及三个变体一对一父组的交集。没有父键时保留为缺失，不用文件行号、函数名相似度或题面推断。一道父题及其所有变体构成同一分组。

这是零 GPU 的来源审计。交集表示可核验的配对数量。它无法证明需求变化导致程序失效、在线可获取边信用，也无法证明公开基准与预训练或本项目历史隔离。协议不授权把公开测试反馈用于策略调参，不改变 Formal10、D26 或其确认集。
