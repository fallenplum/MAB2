# D8 prospective CPU diagnostic: document allocation versus query-only prediction

Freeze before any Formal6 gold labels or quality metrics are opened. This does not alter Formal6 gates and cannot turn its failure into a pass. It is an exploratory root-cause diagnostic on the pilot after it becomes exposed development data. No new model inference, no CI/bootstrap.

Hypothesis: D6 query-only features omit which input documents are allocated to each source, while D7 length/overlap features omit document-level evidence allocation. In the new input-only partition, relevance of documents owned by the changed source may carry decision signal even when query text alone does not. This is a predictor-sufficiency diagnostic, not a new predictor or final acquisition method.

Inputs: only question and ten original document titles/sentences, known graph shock and deterministic3/3/4 partition. Do not use gold, supporting facts, task labels, generated messages, final outputs or costs as features. Per-question lexical BM25 variant uses log(1+(10-df+0.5)/(df+0.5)), k1=1.2,b=0.75 and lowercased Unicode word tokens. No corpus-wide test fitting. For affected/other/relay-owned shards use maximum, mean, sum of top-two document scores, ownership fractions among global top2/top4, and log document lengths; also question token count and binary shock orientation. Normalize score features by the per-question maximum+1e-8. No feature/hyperparameter search.

Targets: two-seed mean complete service utility EM-5e-6*(all input+output tokens) for G1 keep, delete-affected and delete-other. Six question-group folds from PCG64 seed261116801 (16 held-out questions each); all seeds of a question stay together. Compare fold-trained constant action to (1) train-fold StandardScaler + Ridge alpha10; (2) DecisionTreeRegressor depth3,min_samples_leaf12,random_state261116802. Also report a free fixed lexical rule deleting the source with lower top-two BM25 mass; ties choose affected. Select no other action or fallback winner.

Exploratory signal gate per registered model: paired held-out utility gain >=0.005 versus training-selected constant, >=4/6 positive folds, and positive mean gain in both generation seeds. Report fixed actions, all candidates, raw EM, seed and fold decomposition, correction/destruction and token costs. Training/feedback collection cost is not included in service-only utility; therefore a passing diagnostic is not complete-budget evidence. Report any failure and retain all arrays privately. A later mechanism must use new question groups and include equal-budget feedback baselines, free lexical/coverage rules, flat communication and strong single models. If Formal6 fails its fixed gates, it remains failed regardless of D8.

Advantage: directly tests a missing-information explanation with input-only features and no new GPU cost. Risk: tiny96-question exploratory set, lexical relevance may not track multihop utility, credit remains seed-sensitive, and any learned selector can be dominated by free rules or a single model. No ACL novelty claim follows from this diagnostic.
