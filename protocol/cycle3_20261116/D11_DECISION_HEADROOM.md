# D11: bounded decision diagnosis after complete Formal7 scoring

This is a zero-new-GPU, exploratory development analysis, fixed while all Formal7 labels remain sealed. It cannot override any Formal7 gate or turn its96 development questions into independent confirmation. Execute only after complete archive, actual cost closure, CPU replay and independent scoring audit. No fitting, hyperparameter search, confidence intervals or bootstrap.

Questions: (1) Does graph evolution change economically relevant delete/keep directions, rather than only raw credit MSE? (2) Does a free protect-affected/delete-other rule explain nearly all remaining benefit? (3) Is same-question alternate-seed information useful as an unavailable reliability upper bound?

Use the same fixed lambda5e-6 and three graph actions KEEP/DELETE_AFFECTED/DELETE_OTHER. Explicitly map U/V using each input's removed_upstream. Report all three free controls, stale old-graph best-action transfer, current graph optimum with foreknowledge, and alternate-seed current-graph action transfer. Tie order is KEEP,DELETE_AFFECTED,DELETE_OTHER. Every chosen graph pays its actual logical service tokens; historical or alternate-seed observation costs are reported separately and are not silently free. Oracles are unattainable diagnostics, not candidate policies. No oracle can establish active feedback efficacy.

Report overall/per-seed EM,F1,tokens,service utility, action counts, corrections/destructions againstKEEP, changes in old/new utility-preferred actions, positive/negative/zero raw edge credit, net-delete direction errors, and their regret. For the three fixed graph controls, report pairwise points; the retrospective best constant is an explicitly unattainable selection reference, not a trained baseline. Report oracle headroom above every fixed control andSINGLE_Q as ceilings, not realized gains. For every selected action in transfer diagnostics, retain provenance and actual paid prerequisite calls in the private record.

Interpretation is asymmetric: low oracle headroom can rule out substantial improvements for this action set; high headroom cannot show an observable predictor or a cost-effective acquisition policy exists. Stable alternate-seed directions are only reliability evidence. If Formal7 fails any gate it remains failed; use this diagnosis to identify a substantively different mechanism, not tune its threshold. If all gates pass, any predictor/active policy still requires a separately frozen development design and fresh independent confirmation.

Advantage: answers the user's decision-relevance question with fixed existing matrices. Risk: the two-seed train sample is small, benchmark-gold feedback idealized, and perfect-information bounds can greatly overstate achievable policy gain.
