# D12: exploratory terminal annotation intervention

Chosen after the fully audited Formal8 negative result and before reading Formal7 scores. This is an exposed-data failure diagnosis, not a preregistered independent confirmation or a new formal candidate. No gate changes or new GPU calls.

For all96 questions and both seeds, remove only evidence_notes from each archived terminal request and compare the complete remaining request with SINGLE_Q. Model identity, protocol, RNG seed, prompt instruction, raw documents and generation configuration must match. Require full192 matched pairs for G0, G1 and FLAT_ANNOTATION; fail instead of silently restricting these comparisons. Describe other conditions' matching coverage explicitly.

Use the already audited EM arrays to report corrections and destructions on matched pairs. Report literal word-sequence overlap between G1 final answers and incoming notes, separately for corrections, destructions and unchanged outcomes, and separately count multiword matches. Such overlap cannot establish semantic contradiction or mediation.

Reconstruct the cost of always ignoring notes AFTER their prefix has been generated: original prefix input/output tokens plus the matched SINGLE_Q terminal call. This is a paid-prefix diagnostic; no observed prefix cost is erased. It is not a proposed deployable advantage over SINGLE_Q.

Advantages: existing paired actual generations can isolate a terminal input change without another expensive matrix. Risks: realized small-sample effects, source-note content confounding between methods, incidental text overlap, and no individual-note intervention. Preserve all fixed formal failures. No CI/bootstrap. The result guides whether a distinct grounding/abstention mechanism merits testing; it does not admit such a candidate automatically.
