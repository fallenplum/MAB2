# D32 同一篇文章内跨时间条件与图结构的检索信用

这是 CPU 上的机制探针。目标为人工标注答案位置所在段落能否排第一。所有系统使用同一批段落。在静态回顾性文章上改变问题所指的时间，无法推断历史语料更新或小模型最终答案效用。

在作者 TimeQA human_train.easy 里按文章与关系分组。从同文、同关系、段落字节相同、提问中明确的年份范围严格不相交的两问中，选择时间间距最小的一对，平局按固定摘要解决。一篇文章至多一对。排除工程查验过的第一篇，其余按预注册摘要排序，取前 64 篇或全部可用篇。组的选择不用答案、分值和标签。评价只接受官方字符偏移精确落入原段落、且与作者提供的答案别名完全对应的支持段，多解取集合。无法核验的位置单列，禁止替换题目。

词汇节点 L 使用逐文章 BM25，日期节点 D 使用提问年份与段落年份的倒数距离。J 为段落的归一词汇与日期分数乘积。旧图为 L 或 L+D，新图加入 J，比较 L+J 与 L+J+D。保留或删除 D 后的第一个段落确定检索结果。旧问题和新问题交叉两种图及删留干预，真实信用为保留与删除的命中差。J 依赖 L 与 D 的打分，所研究的边是 D 的直接分数通往汇总器，切除直接边时 J 的间接路径继续存在。

历史阶段每题已获得旧问题旧图的成对判断。旧信用非负时保留 D。当前两行动输出相同时所有策略都免费识别其信用为零。每种主动策略可在至多四分之一的可评分文章上购买两个不同段落的相关性判断，预算取上整并受实际行动分歧数限制。购买后按实际信用纠正错误删留。完整公平对照包括不更新、当前排序间隔、跨问题端点变化、三个固定随机排列、均匀周期、直接取单一节点、固定融合、免费知道两行动结果的上界。预选方法首先按固定新问题下更改图时发生变化的两个端点数降序，然后按跨时间跨图变化数降序、当前排序间隔升序和固定摘要破平。所有对照获得同样的可见信息。

进入下一阶段需要至少 32 个可评分文章组、至少 4 组仅因改变当前图而信用变化、理想复检至少能纠正 4 组、候选比每个相同预算对照至少多检对 2 组且不低于最强免费静态检索器。该门只决定是否值得继续实验。保留全部控制、费率、差异和缺失。零模型调用、零 GPU，无 CI、无 bootstrap。未选择的训练文章与官方开发、测试集不得用来更换本探针的阈值或选择另一种失败后策略。不同来源的实际多模型反馈实验仍须独立冻结。
