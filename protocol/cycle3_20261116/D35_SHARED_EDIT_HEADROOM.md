# D35 按外生图变类型向新问题迁移的动作空间

D17 两项任务的逐题理想决策具有正上界，但选择者看到同一题的其他带标签重复。D33 的跨问题冻结策略缺少足够收益。D34 的免费结构对照未与固定边身份充分区分。仍需检验已有短文本协作图中，是否只靠部署前可知的图变化类型就能选择可迁移的编辑，再判断是否值得付费采样或确认。

以 D16 两项各 96 个开发问题、2 个上游种子和 4 个终端种子的原矩阵为输入。按题号的固定摘要划分四折。新题不得用标签和逐题消息选择动作；每折只可针对 3 种外生去边类型各选择一个共享动作。固定候选为保持剩余图、删 U/V/第三边（边已移除时保持）、无消息单接收器。后者对所有策略开放。预估旧策略仅从其余三折的旧图均值和旧图删边值学习；若动作在当前图已无效，将它按保持映射到旧图比较。对比保持、总用单接收器、历史最优全局策略、历史最优按冲击策略。另列有当前带标训练图的跨题策略、看见评估折全部标签后按每个冲击选择的上界及逐题全知上界。只对实际选图中使用的消息计费。旧图历史与上界的选择成本均暂免，因此这一步仅是机会检查。

延续 D17 的 0.005 效用差要求。若两个任务的按冲击上界都高于最强四种廉价基线至少 0.005，且各折均严格优于旧图按冲击选择，则继续执行一个固定预算的跨题采集实验。若不足，则不在这些数据上搜索更多标签切片或调模型。报告全部成本、纠正与损害；8 次同题生成不是 8 道独立题。零新增推理。
