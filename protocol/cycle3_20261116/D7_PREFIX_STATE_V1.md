# D7：生成后前缀状态是否揭示决策信息

假设：D6用问题输入预测的是跨随机生成平均信用，可能丢失源消息质量与冲突；在下游终态生成前，源/接收节点U,V,R的实际消息能够解释一部分同次生成信用。新观察变量具有机制区别，不能声称新架构。

仍仅使用已曝光Formal5数据，零GPU。每题种子为观测，按题leave-one-episode-out8折，所有5种子同折。严禁终态M答案、gold及参考支持事实进入特征。

特征固定：输入metadata，源消息字符/词数、词集合交并比（U/V,U/R,V/R）、相对问题词覆盖，数字词交并比，否定/不确定词计数。将U/V按shock映射为affected/other，G0/G1对应的R状态分别取真实前缀。当前价包括U,V,R全部已观察调用及选定M，因此即使删除affected使其在最终图中成为dead node也不能免收已读取的source成本。

固定函数族：StandardScaler+Ridge(alpha10, solver svd)预测paired deletion gains与训练内M平均成本；一个独立浅树基线(max_depth3,min_samples_leaf80,random_state261116)检验非线性交互。禁止超参搜索。比较：训练选最佳常量图，三静态图，当前信用直接拟合，旧信用预测迁移，当前减旧残差（精确线性等价检查）。

只筛选前缀是否有用，不是完整主动复检机制成功。训练反馈成本另列，效用是包括实际前缀的服务成本，不能宣称含训练标注成本的部署增益。输入/前缀特征收益>=0.005且8折>=6正、至少4/5种子正可保留研究；之后必须新独立样本和明确paid revalidation对照，否则不得启动大正式试验。无信号则转到信息访问/任务机制设计，不扩网络或继续扫特征。
