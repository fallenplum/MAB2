# D31 时间问答的可行性核查

Formal10、D26、D29 和 D30 的结果均保留。停止在其 16 道已曝光题上新增策略。另一个可证伪假设是，当同一问题所指的事实随时间变化时，曾经有用的专家消息可能失效。要将失效归因于图结构，需在两个时间上下文中分别交叉旧图、新图及成对留一边干预，独立计算固定时间下的边信用变化。世界变化本身不能作为图条件作用的证据。

先在 SituatedQA 和 TimeQA 的作者仓库只取官方训练文件。以固定 Git 对象锁定字节。只统计结构、训练问题归组、日期和训练答案别名集合的重叠，原始文本与逐题标记留在本地。跨日期别名无交集只说明文本不同，不自动认定真实世界事实变化。检查是否具有可定位的支持文献和真正独立的证据版本；单一回顾性文章仅支持改变提问时间的实验。尚未检验项目缓存暴露的来源不得称为独立。

如有可用材料，进一步核查文档/实体分组、历史曝光、同成本标量检索和缓存复用。前瞻机制必须对比相同时间和材料的直接回答、按日期检索、沿用历史、随机/周期/不确定性复检。保留世界变化但图固定、图变化但时间固定的两个对照。对源材料的审计不收集生成结果、不打开开发或测试分割，不预留 GPU。
