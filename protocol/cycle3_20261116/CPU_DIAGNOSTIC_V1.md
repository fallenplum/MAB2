# D6：旧数据机制诊断（探索性，新增GPU=0）

输入：第五轮已完全曝光的640题×5种子，冻结PRIVATE_REPLAY SHA dea10c767ff0588d9774fc294863649fe2c012a6f090a9d1b5749145793bcb5e，及相同闭合原始请求。不得打开其他未授权标签或新测试集。

假设族与可证伪预测：
1. 局部I8/C8反馈的估计方差可能遮蔽可复用信号。比较全题五种子平均信用的分布、跨种子稳定性，以及按题池化学习的图决策与训练选择的最佳固定图。
2. 任务条件可能解释信用差异。使用只含输入的metadata或TF-IDF特征，固定Ridge alpha10，无网格，leave-one-episode-out八折；同一题五种子始终同折。预测五种子均值，评估每个保留种子。决策按固定lambda=5e-6的完整服务token效用。训练花费单列，不把探索性路由当免费可部署收益。
3. 图变更的差分信用可能比直接收益更可迁移。比较旧图收益迁移、新图直接拟合、旧图+图变化残差；同样输入和拟合类，不引入更大模型。残差拟合须与直接拟合等式作对照，不能把线性代数等价重命名为创新。
4. 接收消息的精确不变能否证书化信用复用？统计相同问题/种子的G0与G1接收端wire_message相等率与信用变化；先证明权限与输入一致，不把相似文本等价成相同信用。

范围：图动作keep/delete affected/delete other；系统对照singleQ/independent3Q。在每折训练集上选常量最佳图；同时报告固定图、oracle上界（显式不可部署）、同信息简单上下文基线、所有折/种子/成本。元数据含类型、难度、输入长度；TF-IDF在训练折fit，min_df5,max_features512,ngram1-2。没有标签或输出作为输入特征。

CPU筛选门只控制是否值得进一步设计：若某个候选族在八折中至少六折相对训练选常量效用为正、总体差>=0.005，且图类而非单模型选择提供增量，可保留假设。该门不是新独立结果或正式成功。未通过则冻结这一简单特征家族，进行不同机制分析，不扩大网络/调参救结果。oracle若不足以覆盖实际反馈成本则暂缓新增该图族推理。
