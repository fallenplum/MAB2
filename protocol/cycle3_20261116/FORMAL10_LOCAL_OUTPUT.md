# Formal10 本机持久归档与服务器临时文件

按 2026-11-21 用户对存储位置的明确要求，本机实验根目录是主归档，服务器沿用已部署权重，用临时工作目录做推理和可见程序执行。此约定在剩余十题启动前生效。原六题、两道中断题的账本、题集、四卡分派、模型、图、种子、时限、成本门、质量门和隐藏评分规则继续适用。

主归档保留 8 GiB 最低剩余空间。服务器临时目录要求至少 512 MiB 可用，单段工作文件上限 256 MiB。既有六题服务端归档实测 9,277,360 字节。工作进程仍在服务器本地文件系统写入并 fsync 原生日志、运行可见程序。实时传输仅使用现有 SSH/SFTP 连接，由本机主动读取指定目录。

主归档按快照长度拉取新增或变化的文件，校验 SHA-256、fsync 后原子替换。每次成功持久化及本地空间核对后刷新当前批次心跳。服务端每秒检查心跳，180 秒未刷新或临时盘空间不足时监督器停止本批工作进程并关闭账本。服务端暂存允许在网络恢复后补齐最后一批记录。终态要求逐文件对账，试验题质量指标须在两段完整覆盖全部 16 题后计算。128 道独立确认题隔离。

成本包括等待、加载、中断调用和同步对驻留时间的影响。正式段继续使用之前的单活模型放置。将启动前、镜像同步中、归档后的容量分别记入私有回执。
