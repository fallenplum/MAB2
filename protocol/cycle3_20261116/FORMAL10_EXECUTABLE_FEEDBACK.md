## Scope and novelty boundary
D25 supplies1496eligible project-cache-disjoint function-task groups from original APPS TRAIN. No model outcomes have been observed. D23/D24 STDIO failures stand. This new pilot asks whether partial executable feedback can support useful graph-conditional decisions with fixed3B/7Bworkers. It does not claim execution-feedback topology evolution, counterfactual credit, caching, code generation or visible/hidden tests as innovations; AgentConductor,LEMON,CANTANTE,C3 already constrain those claims.
