Question: does the existing three-action space contain even optimistic cost-adjusted decision opportunity, and does such opportunity require selection before or after paying for the default graph?

If both fail, freeze this fixed coding action space and return to mechanism/literature analysis. If only free preselection passes, current post-feedback timing has no certified opportunity under this diagnostic; a different preterminal information mechanism would require a new protocol and independent data. Advantages: separates action-space limits from feedback-acquisition costs without new inference or label-driven tuning.
